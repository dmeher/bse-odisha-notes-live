ପ୍ରତ୍ୟେକ ପ୍ରଶ୍ନର ଚାରୋଟି ବିକଳ୍ପରୁ ଗୋଟିଏ ଉତ୍ତର ବାଛ।

  1. ଗାନ୍ଧିଜୀଙ୍କ ପ୍ରାରମ୍ଭିକ କାର୍ଯ୍ୟ। “ଚମ୍ପାରନ୍‌ର ଚାଷୀଙ୍କ ପାଇଁ ଗାନ୍ଧିଜୀଙ୍କୁ ନିମନ୍ତ୍ରଣ କରିଥିବା ବ୍ୟକ୍ତି” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ପୋରବନ୍ଦର
    2. ରାଜକୁମାର ଶୁକ୍ଳ
    3. ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍
    4. ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ

  2. କ୍ରମରେ ମେଳାଅ। (କ) ଭାରତୀୟଙ୍କୁ ସଙ୍ଗଠିତ କରିବା ପାଇଁ ୧୮୯୪ରେ ଗଠିତ ଅନୁଷ୍ଠାନ। (ଖ) ଦକ୍ଷିଣ ଆଫ୍ରିକାରେ ଭାରତୀୟଙ୍କ ପ୍ରତି ଅନ୍ୟାୟ ପ୍ରଚାର ପାଇଁ ପତ୍ରିକା।

    1. ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ / ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍
    2. ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍ / ରାଜକୁମାର ଶୁକ୍ଳ
    3. ପୋରବନ୍ଦର / ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ
    4. ରାଜକୁମାର ଶୁକ୍ଳ / ପୋରବନ୍ଦର

  3. ଜାତୀୟ ଆନ୍ଦୋଳନର ଘଟଣାକ୍ରମ। “ଅସହଯୋଗ ଆନ୍ଦୋଳନର ଆନୁଷ୍ଠାନିକ ଆରମ୍ଭ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ୬ ଏପ୍ରିଲ ୧୯୩୦
    2. ୧୨ ମାର୍ଚ୍ଚ ୧୯୩୦
    3. ୨୧ ଅକ୍ଟୋବର ୧୯୪୩
    4. ୧ ଅଗଷ୍ଟ ୧୯୨୦

  4. “୬ ଏପ୍ରିଲ ୧୯୩୦” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ଅସହଯୋଗ ଆନ୍ଦୋଳନର ଆନୁଷ୍ଠାନିକ ଆରମ୍ଭ
    2. ସାବରମତୀ ଆଶ୍ରମରୁ ଦାଣ୍ଡି ଅଭିମୁଖେ ଯାତ୍ରାର ଆରମ୍ଭ
    3. ସିଙ୍ଗାପୁରରେ ଆଜାଦ୍ ହିନ୍ଦ୍ ସରକାର ଗଠନ
    4. ଦାଣ୍ଡି ସମୁଦ୍ରକୂଳରେ ଲବଣ ଆଇନ ଭଙ୍ଗ

  5. ସ୍ଥାନ ଓ ଘଟଣା। “୧୯୨୯ରେ ପୂର୍ଣ୍ଣ ସ୍ୱରାଜ ଲକ୍ଷ୍ୟ ନିର୍ଦ୍ଧାରଣ କରିଥିବା କଂଗ୍ରେସ ଅଧିବେଶନ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ଚମ୍ପାରନ୍
    2. ସିଙ୍ଗାପୁର
    3. ଇଞ୍ଚୁଡ଼ି
    4. ଲାହୋର

  6. “ସିଙ୍ଗାପୁର” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ୧୯୨୯ରେ ପୂର୍ଣ୍ଣ ସ୍ୱରାଜ ଲକ୍ଷ୍ୟ ନିର୍ଦ୍ଧାରଣ କରିଥିବା କଂଗ୍ରେସ ଅଧିବେଶନ
    2. ବାଲେଶ୍ୱର ଜିଲ୍ଲାର ଲବଣ ସତ୍ୟାଗ୍ରହ କେନ୍ଦ୍ର
    3. ତିନିକାଠିଆ ବ୍ୟବସ୍ଥାର ପ୍ରତିବାଦ
    4. ଆଜାଦ୍ ହିନ୍ଦ୍ ସରକାର ପ୍ରତିଷ୍ଠାର ସ୍ଥାନ

  7. ପୌରସଂସ୍ଥା ଓ ଲୋକସଭା ନିର୍ବାଚନର ତତ୍ତ୍ୱାବଧାରକଙ୍କ ଠିକ୍ କ୍ରମ କେଉଁଟି?

    1. ରାଜ୍ୟ ନିର୍ବାଚନ ଆୟୋଗ, ଭାରତର ନିର୍ବାଚନ ଆୟୋଗ
    2. ଉଭୟ ପାଇଁ ପୌରସଂସ୍ଥା
    3. ଉଭୟ ପାଇଁ ଜିଲ୍ଲା ପରିଷଦ
    4. ଭାରତର ନିର୍ବାଚନ ଆୟୋଗ, ରାଜ୍ୟ ନିର୍ବାଚନ ଆୟୋଗ

  8. ଜଣେ ସଭ୍ୟଙ୍କ ଦେହାନ୍ତ ପରେ କେବଳ ତାଙ୍କ ଆସନ ପାଇଁ ଭୋଟ ହେଲା। ଏହା କେଉଁ ନିର୍ବାଚନ?

    1. ଉପ-ନିର୍ବାଚନ
    2. ସମଗ୍ର ସଭାର ପୁନର୍ନିର୍ବାଚନ
    3. ମଧ୍ୟବର୍ତ୍ତୀକାଳୀନ ନିର୍ବାଚନ
    4. ସାଧାରଣ ନିର୍ବାଚନ

  9. ଓଡ଼ିଶା ପ୍ରଦେଶ ଗଠନର ପଟଭୂମି। “ସ୍ୱତନ୍ତ୍ର ଓଡ଼ିଶା ପ୍ରଦେଶ ଗଠନ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ୧୮୬୬
    2. ୧୯୦୩
    3. ୧୯୩୬
    4. ୧୮୦୩

  10. ଜମିଦାରୀ ଉଚ୍ଛେଦ ଓ ଭୂଦାନ ଜମିର ବଣ୍ଟନ କୃଷିର କେଉଁ ସମସ୍ୟା ସହ ସିଧାସଳଖ ଜଡ଼ିତ?

    1. ବନ୍ଦରର ଗଭୀରତା
    2. ମୌସୁମୀର ଆଗମନ
    3. ଜମିର ମାଲିକାନା
    4. ଖଣିଜ ନିଷ୍କାସନ

  11. ବ୍ୟକ୍ତି ଓ ଅବଦାନ। “ଉତ୍କଳ ସମ୍ମିଳନୀର ପ୍ରଥମ ଅଧିବେଶନର ସଭାପତି” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ହରେକୃଷ୍ଣ ମହତାବ
    2. ଶ୍ରୀରାମଚନ୍ଦ୍ର ଭଞ୍ଜଦେଓ
    3. କୃଷ୍ଣଚନ୍ଦ୍ର ଗଜପତି
    4. ମଧୁସୂଦନ ଦାସ

  12. ଆନ୍ଧ୍ର ଗଠନର ଦାବିରେ କେଉଁ ଭିତ୍ତି ଅନ୍ୟ ଅଞ୍ଚଳରେ ମଧ୍ୟ ସମାନ ଦାବିକୁ ଉତ୍ସାହ ଦେଲା?

    1. ନଦୀବନ୍ଧ
    2. ଭାଷା
    3. ବାର୍ଷିକ ବୃଷ୍ଟିପାତ
    4. ଖଣିର ଗଭୀରତା

  13. ସ୍ୱାଧୀନତା ଓ ଶାସନ। “ସ୍ୱାଧୀନ ଭାରତର ପ୍ରଥମ ଗଭର୍ଣ୍ଣର ଜେନେରାଲ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ଲର୍ଡ ମାଉଣ୍ଟବ୍ୟାଟେନ
    2. ମହମ୍ମଦ ଅଲ୍ଲୀ ଜିନ୍ନା
    3. ଜବାହରଲାଲ ନେହେରୁ
    4. ଲିଆକତ୍ ଅଲ୍ଲୀ ଖାଁ

  14. କ୍ରମରେ ମେଳାଅ। (କ) ପାକିସ୍ତାନର ପ୍ରଥମ ଗଭର୍ଣ୍ଣର ଜେନେରାଲ। (ଖ) ସ୍ୱାଧୀନ ଭାରତର ପ୍ରଥମ ପ୍ରଧାନମନ୍ତ୍ରୀ।

    1. ମହମ୍ମଦ ଅଲ୍ଲୀ ଜିନ୍ନା / ଜବାହରଲାଲ ନେହେରୁ
    2. ଲିଆକତ୍ ଅଲ୍ଲୀ ଖାଁ / ମହମ୍ମଦ ଅଲ୍ଲୀ ଜିନ୍ନା
    3. ଜବାହରଲାଲ ନେହେରୁ / ଲର୍ଡ ମାଉଣ୍ଟବ୍ୟାଟେନ
    4. ଲର୍ଡ ମାଉଣ୍ଟବ୍ୟାଟେନ / ଲିଆକତ୍ ଅଲ୍ଲୀ ଖାଁ

  15. ବିକାଶ ଓ ରାଷ୍ଟ୍ରଗଠନ। “ଚାଷ ଆରମ୍ଭ କରିବାକୁ କୃଷକଙ୍କୁ ଦିଆଯାଉଥିବା ଋଣ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ମିଳନ ପତ୍ର
    2. ତକାଭି ଋଣ
    3. APPLE
    4. ବିଜୁ ଗ୍ରାମଜ୍ୟୋତି

  16. “ମିଳନ ପତ୍ର” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ପଟେଲ ଓ ମେନନଙ୍କ ଦ୍ୱାରା ଦେଶୀୟ ରାଜ୍ୟର ମିଶ୍ରଣ ପାଇଁ ପ୍ରସ୍ତୁତ ଦଲିଲ
    2. ଶହେରୁ କମ୍ ଲୋକ ଥିବା ଗାଁର ବିଦ୍ୟୁତୀକରଣ ପାଇଁ ରାଜ୍ୟ ଯୋଜନା
    3. ୧୯୮୧ ଜୁନ୍‌ରେ ଉତ୍‌କ୍ଷେପିତ ଭାରତୀୟ ଯୋଗାଯୋଗ ଉପଗ୍ରହ
    4. ଚାଷ ଆରମ୍ଭ କରିବାକୁ କୃଷକଙ୍କୁ ଦିଆଯାଉଥିବା ଋଣ

  17. ରାଜ୍ୟ ପୁନଃଗଠନ। “୨ ଜୁନ୍ ୨୦୧୪ରେ ଗଠିତ ରାଜ୍ୟ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. କର୍ଣ୍ଣାଟକ
    2. ଗୋଆ
    3. ତେଲେଙ୍ଗାନା
    4. ତାମିଲନାଡୁ

  18. “କର୍ଣ୍ଣାଟକ” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ମହୀଶୂର ରାଜ୍ୟର ପରିବର୍ତ୍ତିତ ନାମ
    2. ୧୯୬୧ରେ ଭାରତରେ ମିଶି ୧୯୮୭ରେ ରାଜ୍ୟ ହୋଇଥିବା ଅଞ୍ଚଳ
    3. ୨ ଜୁନ୍ ୨୦୧୪ରେ ଗଠିତ ରାଜ୍ୟ
    4. ମାଡ୍ରାସ୍ ରାଜ୍ୟର ପରିବର୍ତ୍ତିତ ନାମ

  19. ନିର୍ବାଚନର ପରିସ୍ଥିତି। “ସଭା ଭଙ୍ଗ ନ ହୋଇ ଗୋଟିଏ ଆସନର ଅବଶିଷ୍ଟ କାଳ ପାଇଁ ଚୟନ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ପରୋକ୍ଷ ନିର୍ବାଚନ
    2. ପ୍ରତ୍ୟକ୍ଷ ନିର୍ବାଚନ
    3. ଉପ-ନିର୍ବାଚନ
    4. ମଧ୍ୟବର୍ତ୍ତୀକାଳୀନ ନିର୍ବାଚନ

  20. କ୍ରମରେ ମେଳାଅ। (କ) ଜନସାଧାରଣ ସିଧାସଳଖ ଲୋକସଭା ସଦସ୍ୟ ବାଛିବାର ପଦ୍ଧତି। (ଖ) ନିର୍ବାଚକ ମଣ୍ଡଳୀ ମାଧ୍ୟମରେ ରାଷ୍ଟ୍ରପତି ବାଛିବାର ପଦ୍ଧତି।

    1. ପରୋକ୍ଷ ନିର୍ବାଚନ / ଉପ-ନିର୍ବାଚନ
    2. ପ୍ରତ୍ୟକ୍ଷ ନିର୍ବାଚନ / ପରୋକ୍ଷ ନିର୍ବାଚନ
