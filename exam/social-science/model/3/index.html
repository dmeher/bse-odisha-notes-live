ପ୍ରତ୍ୟେକ ପ୍ରଶ୍ନର ଚାରୋଟି ବିକଳ୍ପରୁ ଗୋଟିଏ ଉତ୍ତର ବାଛ।

  1. ଗାନ୍ଧିଜୀଙ୍କ ପ୍ରାରମ୍ଭିକ କାର୍ଯ୍ୟ। “ଭାରତୀୟଙ୍କୁ ସଙ୍ଗଠିତ କରିବା ପାଇଁ ୧୮୯୪ରେ ଗଠିତ ଅନୁଷ୍ଠାନ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ରାଜକୁମାର ଶୁକ୍ଳ
    2. ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ
    3. ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍
    4. ପୋରବନ୍ଦର

  2. କ୍ରମରେ ମେଳାଅ। (କ) ଚମ୍ପାରନ୍‌ର ଚାଷୀଙ୍କ ପାଇଁ ଗାନ୍ଧିଜୀଙ୍କୁ ନିମନ୍ତ୍ରଣ କରିଥିବା ବ୍ୟକ୍ତି। (ଖ) ଗାନ୍ଧିଜୀଙ୍କ ଜନ୍ମସ୍ଥାନ।

    1. ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍ / ରାଜକୁମାର ଶୁକ୍ଳ
    2. ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ / ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍
    3. ପୋରବନ୍ଦର / ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ
    4. ରାଜକୁମାର ଶୁକ୍ଳ / ପୋରବନ୍ଦର

  3. ୧୯୭୪ରେ ସହଯୋଗୀ ରାଜ୍ୟ ଓ ପରବର୍ତ୍ତୀ ବର୍ଷରେ ପୂର୍ଣ୍ଣ ରାଜ୍ୟ ହେବାର ଘଟଣା କାହା କ୍ଷେତ୍ରରେ ଘଟିଥିଲା?

    1. ସିକିମ୍
    2. ଗୋଆ
    3. ମାଡ୍ରାସ୍
    4. ମହୀଶୂର

  4. “୧ ଅଗଷ୍ଟ ୧୯୨୦” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ସାବରମତୀ ଆଶ୍ରମରୁ ଦାଣ୍ଡି ଅଭିମୁଖେ ଯାତ୍ରାର ଆରମ୍ଭ
    2. ଦାଣ୍ଡି ସମୁଦ୍ରକୂଳରେ ଲବଣ ଆଇନ ଭଙ୍ଗ
    3. ଅସହଯୋଗ ଆନ୍ଦୋଳନର ଆନୁଷ୍ଠାନିକ ଆରମ୍ଭ
    4. ସିଙ୍ଗାପୁରରେ ଆଜାଦ୍ ହିନ୍ଦ୍ ସରକାର ଗଠନ

  5. ବିଦ୍ୟାଳୟରେ ନାମ ଲେଖାଇବା ପରେ ଅନେକ ପିଲା ପାଠ ଛାଡ଼ୁଥିଲେ। ପ୍ରାଥମିକ ଶିକ୍ଷାର ବିକାଶ ମାପିବାରେ କେଉଁ ତଥ୍ୟଟି ବିଶେଷ ପ୍ରାସଙ୍ଗିକ?

    1. କେତେ ବନ୍ଦର ନିର୍ମାଣ ହେଲା
    2. କେତେ ଖଣି ଖୋଲିଲା
    3. କେତେ ପିଲା ପାଠ ଜାରି ରଖିଲେ
    4. କେତେ ଜମିରେ ଜଳସେଚନ ହେଲା

  6. “ଲାହୋର” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ବାଲେଶ୍ୱର ଜିଲ୍ଲାର ଲବଣ ସତ୍ୟାଗ୍ରହ କେନ୍ଦ୍ର
    2. ଆଜାଦ୍ ହିନ୍ଦ୍ ସରକାର ପ୍ରତିଷ୍ଠାର ସ୍ଥାନ
    3. ତିନିକାଠିଆ ବ୍ୟବସ୍ଥାର ପ୍ରତିବାଦ
    4. ୧୯୨୯ରେ ପୂର୍ଣ୍ଣ ସ୍ୱରାଜ ଲକ୍ଷ୍ୟ ନିର୍ଦ୍ଧାରଣ କରିଥିବା କଂଗ୍ରେସ ଅଧିବେଶନ

  7. ଖଣିଜସମୃଦ୍ଧ ଅଞ୍ଚଳରେ କଳକାରଖାନା କାର୍ଯ୍ୟକ୍ଷମ ହେବା ପାଇଁ କଞ୍ଚାମାଲ ସହ କେଉଁ ସମାହାର ଆବଶ୍ୟକ?

    1. କେବଳ ଅଧିକ ବୃଷ୍ଟିପାତ
    2. କେବଳ ଅଧିକ ଜଙ୍ଗଲ
    3. ବିଦ୍ୟୁତ୍, ପରିବହନ ଓ ଦକ୍ଷ ଶ୍ରମିକ
    4. କେବଳ ଅଧିକ କୃଷିଜମି

  8. ୧୯୪୭ର ବ୍ୟବସ୍ଥାରେ ଜବରଦଖଲ ହୋଇଥିବା ଆଦିବାସୀ ଜମି ଚିହ୍ନଟ ପରେ କ’ଣ କରିବାର ଥିଲା?

    1. ଜମିକୁ ବନ୍ଦର ପାଇଁ ଦେବା
    2. ଶିଳ୍ପ ପ୍ରତିଷ୍ଠାନକୁ ବିକିବା
    3. ଜମିଦାରଙ୍କୁ ଦାନ କରିବା
    4. ପ୍ରକୃତ ଅଧିକାରୀଙ୍କୁ ଫେରାଇବା

  9. ଓଡ଼ିଶା ପ୍ରଦେଶ ଗଠନର ପଟଭୂମି। “ନଅଙ୍କ ଦୁର୍ଭିକ୍ଷ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ୧୯୦୩
    2. ୧୮୦୩
    3. ୧୮୬୬
    4. ୧୯୩୬

  10. କୌଣସି ରାଜ୍ୟର ନାମ ବଦଳାଇବା ପାଇଁ ଭାରତରେ କିଏ ଆଇନ ପ୍ରଣୟନ କରନ୍ତି?

    1. ଜିଲ୍ଲା ପରିଷଦ
    2. ସଂସଦ
    3. ରାଜ୍ୟ ନିର୍ବାଚନ ଆୟୋଗ
    4. ଗ୍ରାମସଭା

  11. ବ୍ୟକ୍ତି ଓ ଅବଦାନ। “ନିଜ ପ୍ରଧାନମନ୍ତ୍ରୀ ପଦର ଦରମା ଉତ୍କଳ ବିଶ୍ୱବିଦ୍ୟାଳୟକୁ ଦାନ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. କୃଷ୍ଣଚନ୍ଦ୍ର ଗଜପତି
    2. ମଧୁସୂଦନ ଦାସ
    3. ହରେକୃଷ୍ଣ ମହତାବ
    4. ଶ୍ରୀରାମଚନ୍ଦ୍ର ଭଞ୍ଜଦେଓ

  12. “ଶ୍ରୀରାମଚନ୍ଦ୍ର ଭଞ୍ଜଦେଓ” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ଓଡ଼ିଶା ସହ ଗଡ଼ଜାତ ମିଶ୍ରଣ ସମୟରେ ସରକାରର ନେତୃତ୍ୱ
    2. ନିଜ ପ୍ରଧାନମନ୍ତ୍ରୀ ପଦର ଦରମା ଉତ୍କଳ ବିଶ୍ୱବିଦ୍ୟାଳୟକୁ ଦାନ
    3. ଉତ୍କଳ ସମ୍ମିଳନୀର ପ୍ରଥମ ଅଧିବେଶନର ସଭାପତି
    4. ଉତ୍କଳ ସମ୍ମିଳନୀ ଗଠନ ଉଦ୍ୟମରେ ଉତ୍କଳ ଗୌରବ

  13. ସ୍ୱାଧୀନତା ଓ ଶାସନ। “ପାକିସ୍ତାନର ପ୍ରଥମ ଗଭର୍ଣ୍ଣର ଜେନେରାଲ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ମହମ୍ମଦ ଅଲ୍ଲୀ ଜିନ୍ନା
    2. ଜବାହରଲାଲ ନେହେରୁ
    3. ଲିଆକତ୍ ଅଲ୍ଲୀ ଖାଁ
    4. ଲର୍ଡ ମାଉଣ୍ଟବ୍ୟାଟେନ

  14. କ୍ରମରେ ମେଳାଅ। (କ) ସ୍ୱାଧୀନ ଭାରତର ପ୍ରଥମ ଗଭର୍ଣ୍ଣର ଜେନେରାଲ। (ଖ) ପାକିସ୍ତାନର ପ୍ରଥମ ପ୍ରଧାନମନ୍ତ୍ରୀ।

    1. ମହମ୍ମଦ ଅଲ୍ଲୀ ଜିନ୍ନା / ଜବାହରଲାଲ ନେହେରୁ
    2. ଲର୍ଡ ମାଉଣ୍ଟବ୍ୟାଟେନ / ଲିଆକତ୍ ଅଲ୍ଲୀ ଖାଁ
    3. ଲିଆକତ୍ ଅଲ୍ଲୀ ଖାଁ / ମହମ୍ମଦ ଅଲ୍ଲୀ ଜିନ୍ନା
    4. ଜବାହରଲାଲ ନେହେରୁ / ଲର୍ଡ ମାଉଣ୍ଟବ୍ୟାଟେନ

  15. ବିକାଶ ଓ ରାଷ୍ଟ୍ରଗଠନ। “ପଟେଲ ଓ ମେନନଙ୍କ ଦ୍ୱାରା ଦେଶୀୟ ରାଜ୍ୟର ମିଶ୍ରଣ ପାଇଁ ପ୍ରସ୍ତୁତ ଦଲିଲ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. APPLE
    2. ମିଳନ ପତ୍ର
    3. ବିଜୁ ଗ୍ରାମଜ୍ୟୋତି
    4. ତକାଭି ଋଣ

  16. “ତକାଭି ଋଣ” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ଶହେରୁ କମ୍ ଲୋକ ଥିବା ଗାଁର ବିଦ୍ୟୁତୀକରଣ ପାଇଁ ରାଜ୍ୟ ଯୋଜନା
    2. ୧୯୮୧ ଜୁନ୍‌ରେ ଉତ୍‌କ୍ଷେପିତ ଭାରତୀୟ ଯୋଗାଯୋଗ ଉପଗ୍ରହ
    3. ଚାଷ ଆରମ୍ଭ କରିବାକୁ କୃଷକଙ୍କୁ ଦିଆଯାଉଥିବା ଋଣ
    4. ପଟେଲ ଓ ମେନନଙ୍କ ଦ୍ୱାରା ଦେଶୀୟ ରାଜ୍ୟର ମିଶ୍ରଣ ପାଇଁ ପ୍ରସ୍ତୁତ ଦଲିଲ

  17. ରାଜ୍ୟ ପୁନଃଗଠନ। “ମହୀଶୂର ରାଜ୍ୟର ପରିବର୍ତ୍ତିତ ନାମ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ତାମିଲନାଡୁ
    2. କର୍ଣ୍ଣାଟକ
    3. ତେଲେଙ୍ଗାନା
    4. ଗୋଆ

  18. “ତେଲେଙ୍ଗାନା” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ମହୀଶୂର ରାଜ୍ୟର ପରିବର୍ତ୍ତିତ ନାମ
    2. ୨ ଜୁନ୍ ୨୦୧୪ରେ ଗଠିତ ରାଜ୍ୟ
    3. ମାଡ୍ରାସ୍ ରାଜ୍ୟର ପରିବର୍ତ୍ତିତ ନାମ
    4. ୧୯୬୧ରେ ଭାରତରେ ମିଶି ୧୯୮୭ରେ ରାଜ୍ୟ ହୋଇଥିବା ଅଞ୍ଚଳ

  19. ନିର୍ବାଚନର ପରିସ୍ଥିତି। “ଜନସାଧାରଣ ସିଧାସଳଖ ଲୋକସଭା ସଦସ୍ୟ ବାଛିବାର ପଦ୍ଧତି” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ପ୍ରତ୍ୟକ୍ଷ ନିର୍ବାଚନ
    2. ମଧ୍ୟବର୍ତ୍ତୀକାଳୀନ ନିର୍ବାଚନ
    3. ଉପ-ନିର୍ବାଚନ
    4. ପରୋକ୍ଷ ନିର୍ବାଚନ

  20. କ୍ରମରେ ମେଳାଅ। (କ) ସଭା ଭଙ୍ଗ ନ ହୋଇ ଗୋଟିଏ ଆସନର ଅବଶିଷ୍ଟ କାଳ ପାଇଁ ଚୟନ। (ଖ) ନିର୍ଦ୍ଧାରିତ ସମୟ ପୂର୍ବରୁ ସଭା ଭଙ୍ଗ ହେତୁ ନୂଆ ସଭା ଚୟନ।
