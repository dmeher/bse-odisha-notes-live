ନମ୍ବର ବଣ୍ଟନ

୨ ଘଣ୍ଟା ୪୫ ମିନିଟ୍ · ୧୦୦ ନମ୍ବର

ବହୁବିକଳ୍ପ ଭାଗରେ ୫୦ଟି ପ୍ରଶ୍ନ × ୧ ନମ୍ବର। ନିମ୍ନ ତାଲିକା ଅନୁସାରେ ବର୍ଣ୍ଣନାମୂଳକ ଭାଗରେ ମୋଟ ୫୦ ନମ୍ବର।

ବିଭାଗପ୍ରଶ୍ନର ପ୍ରକାରନମ୍ବର

ପ୍ରତ୍ୟେକ ୫ ନମ୍ବରର ଅଂଶରେ ବିକଳ୍ପ ଅଛି। ଅଙ୍କନ ପାଇଁ ୫ ନମ୍ବର ନିର୍ଦ୍ଧାରିତ। ଗ୍ରାଫ୍‌, ସଂଖ୍ୟାମୂଳକ ପ୍ରଶ୍ନ କିମ୍ବା ଅନ୍ୟ ଚିତ୍ର ପାଇଁ ଅଲଗା ନିର୍ଦ୍ଧାରିତ ନମ୍ବର ଉଲ୍ଲେଖ ନାହିଁ।

ବୋର୍ଡର ନମ୍ବର ତାଲିକା · ପୃଷ୍ଠା ୮ · ୨୦୨୬–୨୭ ବିଜ୍ଞପ୍ତି

ଆମ ଅଭ୍ୟାସ ସେଟ୍‌ରେ କେଉଁ ଅଧ୍ୟାୟରୁ କେତେ ନମ୍ବର?

ବୋର୍ଡ ଘୋଷଣା କରିଥିବା ବିଭାଗର ନମ୍ବର ଅନୁସାରେ ପ୍ରତିଟି ସେଟ୍ ତିଆରି ହୋଇଛି। ଅଧ୍ୟାୟ ବଣ୍ଟନ ସେଟ୍ ଅନୁସାରେ ବଦଳେ। ତଳେ କେବଳ ଏହି ଅଭ୍ୟାସ ପ୍ରଶ୍ନପତ୍ରଗୁଡ଼ିକର ପ୍ରକୃତ ଗଣନା ଦିଆଯାଇଛି।

ପୂର୍ବ ବର୍ଷର ପ୍ରଶ୍ନ ବିଶ୍ଳେଷଣ

୨୦୨୪ Set D ଓ ୨୦୨୬ Set Bରେ ମୂଳ ବୀଜଗଣିତ ୨୨, ସଡ଼କ ସୁରକ୍ଷା ୨ ଓ ଜ୍ୟାମିତି ୨୬ଟି MCQ ଥିଲା। ୨୦୨୫ Set Aରେ ଏହି ଗଣନା ଯଥାକ୍ରମେ ୨୩, ୨ ଓ ୨୫। ଅଭ୍ୟାସ ସେଟ୍‌ରେ ଦିଆଯାଇଥିବା ବହିର ପାଠଗୁଡ଼ିକୁ ନିଆଯାଇଛି।

ପ୍ରତି ବର୍ଷର ଗୋଟିଏ ସେଟ୍‌ର ସମ୍ପୂର୍ଣ୍ଣ ୫୦ଟି MCQ। ପ୍ରଥମ ଦୁଇ ସ୍ତମ୍ଭ ଅଧ୍ୟାୟ ଅନୁସାରେ। ଶେଷ ସ୍ତମ୍ଭ ପ୍ରଶ୍ନ ସହ ଛପା ଚିତ୍ର ଅନୁସାରେ। ଗୋଟିଏ ପ୍ରଶ୍ନ ଉଭୟ ଗଣନାରେ ଆସିପାରେ।

ଏଗୁଡ଼ିକ ପୁରୁଣା ପ୍ରଶ୍ନପତ୍ରର ଗଣନା। ଏକା ବର୍ଷର ସେଟ୍‌ରେ କ୍ରମ ବଦଳିଥିବା ସମାନ ପ୍ରଶ୍ନକୁ ଗୋଟିଏ ଥର ଗଣାଯାଇଛି। ପ୍ରଶ୍ନ ସଂଖ୍ୟା ଓ ମୂଳ ସ୍କାନ୍ ଦେଖିବାକୁ ବର୍ଷ ଓ ସେଟ୍ ବାଛନ୍ତୁ।

  • ଏହି Set Bର ସ୍କାନ୍‌ରେ ଚିତ୍ର ଦିଆଯାଇଥିବା ୯ଟି ଏକ ନମ୍ବରର ପ୍ରଶ୍ନ ଚିହ୍ନଟ ହେଲା (ପ୍ର. ୨, ୩, ୪, ୧୦, ୨୨, ୨୫, ୩୦, ୩୩, ୪୫)। ବୃତ୍ତର କୋଣ, ସ୍ପର୍ଶକ, ସମାନ୍ତର ରେଖା ଓ ରେଖାଖଣ୍ଡର ବିଭାଜନ ଏଥିରେ ଅଛି। ଏହା ୨୦୨୬ର ଗୋଟିଏ ସେଟ୍‌ରେ ଦେଖାଯାଇଥିବା ବଣ୍ଟନ।
  • ପ୍ରଶ୍ନ ୬ରେ ଦୁଇଟି ସମୀକରଣର ସରଳରେଖା ଛେଦ କରନ୍ତି, ସମାନ୍ତର କିମ୍ବା ସମ୍ପାତୀ ତାହା ଚିହ୍ନିବାକୁ ହୁଏ। ଏଠାରେ ଲେଖଚିତ୍ରର ଧାରଣା ପରୀକ୍ଷା କରାଯାଇଛି। ପ୍ରଶ୍ନ ୭ରେ ସ୍ଥାନାଙ୍କରୁ ଦୂରତା ନିର୍ଣ୍ଣୟ କରିବାକୁ ହୁଏ।
  • ପ୍ରଶ୍ନ ୪ରେ ବୃତ୍ତର ଚିତ୍ରରୁ କୋଣ ନିର୍ଣ୍ଣୟ କରିବାକୁ ହୁଏ। ପ୍ରଶ୍ନ ୫ରେ ସଦୃଶ ତ୍ରିଭୁଜର ଅନୁରୂପ ବାହୁ ଚିହ୍ନି ଚାରିଟି ସମ୍ପର୍କ ମଧ୍ୟରୁ ଭୁଲଟି ବାଛିବାକୁ ହୁଏ।
