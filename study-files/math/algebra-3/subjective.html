୧. ପ୍ରଥମ n ପଦର ସମଷ୍ଟି ସୂତ୍ର କିପରି ଆସେ?

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. Sₙ = a + (a + d) + … + tₙ ଲେଖ। ଓଲଟା କ୍ରମରେ ମଧ୍ୟ ସେହି ସମଷ୍ଟି ଲେଖ।
  2. ଦୁଇ ଧାଡ଼ି ଯୋଗ କଲେ ପ୍ରତି ସ୍ତମ୍ଭର ଯୋଗ a + tₙ। ଏପରି n ଟି ସ୍ତମ୍ଭ।
  3. 2Sₙ = n(a + tₙ) ର ଉଭୟ ପାର୍ଶ୍ୱକୁ 2 ଦ୍ୱାରା ଭାଗ କର।

Sₙ = n(a + tₙ)/2।

୨. −5, −3, −1, 1, … ସମାନ୍ତର ପ୍ରଗତିର ଏକାଦଶ ପଦ ଓ ପ୍ରଥମ ଏଗାର ପଦର ସମଷ୍ଟି ନିର୍ଣ୍ଣୟ କର। ଶେଷ ପଦ ସାହାଯ୍ୟରେ ସମଷ୍ଟି ଯାଞ୍ଚ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୧b (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. a = −5, d = (−3) − (−5) = 2 ଏବଂ n = 11।
  2. t₁₁ = a + 10d = −5 + 20 = 15।
  3. S₁₁ = 11[2(−5) + 10 × 2]/2 = 11 × 10/2 = 55।
  4. ଯାଞ୍ଚ ପାଇଁ 11(a + t₁₁)/2 = 11(−5 + 15)/2 = 55।

t₁₁ = 15 ଓ S₁₁ = 55।

୩. 3, x, 9 ଏକ ସମାନ୍ତର ପ୍ରଗତିର ପ୍ରଥମ ତିନି ପଦ। x, ସାଧାରଣ ଅନ୍ତର, ଦଶମ ପଦ ଓ ପ୍ରଥମ ଦଶ ପଦର ସମଷ୍ଟି ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୧b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. କ୍ରମାଗତ ପଦର ଅନ୍ତର ସମାନ, ତେଣୁ x − 3 = 9 − x।
  2. 2x = 12 ⇒ x = 6; d = 6 − 3 = 3।
  3. t₁₀ = 3 + 9 × 3 = 30।
  4. S₁₀ = 10(3 + 30)/2 = 165।

x = 6, d = 3, t₁₀ = 30 ଓ S₁₀ = 165।

୪. ସମାନ୍ତର ପ୍ରଗତିର ଦ୍ୱିତୀୟ ପଦ 4 ଓ ପଞ୍ଚମ ପଦ 13। ପ୍ରଥମ ପଦ, ସାଧାରଣ ଅନ୍ତର ଓ ପ୍ରଥମ 8 ପଦର ସମଷ୍ଟି ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୨, ଭାଗ ୨, ପ୍ରଶ୍ନ ୧b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. a + d = 4 ଓ a + 4d = 13।
  2. ବିୟୋଗ କଲେ 3d = 9 ⇒ d = 3, a = 4 − 3 = 1।
  3. 8-ତମ ପଦ = 1 + 7 × 3 = 22।
  4. S = n(a + tₙ)/2 = 8(1 + 22)/2 = 92।

a = 1, d = 3, S = 92।

୫. 1, 4, 7, … ର କେତେ ପଦ ନେଲେ ଶେଷ ପଦ 22 ହେବ? ସେହି ପଦଗୁଡ଼ିକର ସମଷ୍ଟି ଓ ପରବର୍ତ୍ତୀ ପଦ ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର ଦେଖନ୍ତୁ

  2. n − 1 = (22 − 1)/3 = 7, ତେଣୁ n = 8।
  3. Sₙ = 8(1 + 22)/2 = 92।
  4. ପରବର୍ତ୍ତୀ ପଦ = 22 + 3 = 25।

୬. ସମାନ୍ତର ପ୍ରଗତିର ଦ୍ୱିତୀୟ ପଦ 6 ଓ ପଞ୍ଚମ ପଦ 18। ପ୍ରଥମ ପଦ, ସାଧାରଣ ଅନ୍ତର ଓ ପ୍ରଥମ 9 ପଦର ସମଷ୍ଟି ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୩, ଭାଗ ୨, ପ୍ରଶ୍ନ ୧a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)
