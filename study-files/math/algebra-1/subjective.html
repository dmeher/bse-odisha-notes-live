୧. ଲେଖଚିତ୍ରର ଛେଦବିନ୍ଦୁ କାହିଁକି ସମାଧାନ ଦିଏ?

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ପ୍ରଥମ ରେଖାର ପ୍ରତ୍ୟେକ ବିନ୍ଦୁ ପ୍ରଥମ ସମୀକରଣକୁ ସିଦ୍ଧ କରେ।
  2. ଛେଦବିନ୍ଦୁ ଦ୍ୱିତୀୟ ରେଖା ଉପରେ ମଧ୍ୟ ଥାଏ। ତେଣୁ ସେହି ଏକ ଯୋଡ଼ି ଦ୍ୱିତୀୟ ସମୀକରଣର ମଧ୍ୟ ସମାଧାନ।

ଛେଦବିନ୍ଦୁର ସ୍ଥାନାଙ୍କ ଯୋଡ଼ି ଉଭୟ ସମୀକରଣକୁ ସିଦ୍ଧ କରେ।

୨. x + y + 1 = 0 ଓ x − y + 1 = 0 କୁ ଲେଖଚିତ୍ରରେ ଅଙ୍କନ କର। ଛେଦବିନ୍ଦୁରୁ ସମାଧାନ ଲେଖ ଓ ଯାଞ୍ଚ କର।

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ପ୍ରଥମ ରେଖା ପାଇଁ y = −1 − x। x = −2 ଓ 0 ରଖିଲେ କ୍ରମେ y = 1 ଓ −1।
  2. ଦ୍ୱିତୀୟ ରେଖା ପାଇଁ y = x + 1। x = −2 ଓ 0 ରଖିଲେ କ୍ରମେ y = −1 ଓ 1।
  3. ଉଭୟ ଅକ୍ଷରେ ସମାନ ମାପକ ନିଅ। (−2, 1), (0, −1) କୁ ଯୋଡ଼। ଅନ୍ୟ ରେଖା ପାଇଁ (−2, −1), (0, 1) କୁ ଯୋଡ଼।
  4. ଦୁଇ ରେଖା (−1, 0) ଠାରେ ପରସ୍ପରକୁ ଛେଦ କରେ।
  5. ଯାଞ୍ଚ କଲେ −1 + 0 + 1 = 0 ଓ −1 − 0 + 1 = 0।

  2. (ii) ଦୁଇ ସମୀକରଣ ଯୋଗ କଲେ 4x = 0; ତେଣୁ x = 0।
  3. x = 0 ବସାଇଲେ −y + 3 = 0 ⇒ y = 3।
  4. ଯାଞ୍ଚରେ 2 × 0 + 3 − 3 = 0। ଦୁଇଟି ଭିନ୍ନ ରେଖାର ଏକମାତ୍ର ଛେଦବିନ୍ଦୁ (0, 3)।

(i) ଅସଂଖ୍ୟ ସମାଧାନ। (ii) ଅନନ୍ୟ ସମାଧାନ (0, 3)।

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ଭୂସମାନ୍ତର x-ଅକ୍ଷ ଓ ଲମ୍ବ y-ଅକ୍ଷ ଆଙ୍କି ଉଭୟରେ ସମାନ ଏକକ ନିଅ। x + y = 6 ପାଇଁ x = 0 ହେଲେ y = 6, y = 0 ହେଲେ x = 6। (0, 6) ଓ (6, 0) ଚିହ୍ନି ଯୋଗ କର।
  2. x − y = 2 ପାଇଁ y = 0 ହେଲେ x = 2। x = 3 ହେଲେ y = 1। (2, 0) ଓ (3, 1)କୁ ଚିହ୍ନି ଦ୍ୱିତୀୟ ରେଖା ଟାଣ।
  3. ରେଖାଦ୍ୱୟର ଛେଦବିନ୍ଦୁରୁ ଉଭୟ ଅକ୍ଷକୁ ଲମ୍ବ ଟାଣି ପଢ଼। ଭୁଜ 4 ଓ କୋଟି 2 ମିଳିବ।
  4. ଯାଞ୍ଚ କର। 4 + 2 = 6 ଓ 4 − 2 = 2। ଦୁଇଟି ଭିନ୍ନ ସରଳରେଖା ଠିକ୍ ଗୋଟିଏ ବିନ୍ଦୁରେ ଛେଦ କରିଛନ୍ତି। ତେଣୁ ଏହି ଯୋଡ଼ି ଏକମାତ୍ର ସମାଧାନ।

ଛେଦବିନ୍ଦୁ P(4, 2)। ଅନନ୍ୟ ସମାଧାନ x = 4, y = 2।

  2. x = 9 ରଖିଲେ 2y = 57 − 45 = 12 ⇒ y = 6।

  4. ଅନ୍ୟ m ରେ ଦ୍ୱିତୀୟଟିରୁ ପ୍ରଥମଟିର ଦୁଇଗୁଣ ବିୟୋଗ କଲେ 0 = m − 114 ହୁଏ, ଯାହା ଅସମ୍ଭବ।

m = 114; ଏକ ସମାଧାନ (9, 6)। ଅନ୍ୟ m ପାଇଁ ସମାଧାନ ନାହିଁ।

୧୧. ଦୁଇଟି ସଂଖ୍ୟାର ସମଷ୍ଟି 15। ପ୍ରଥମର ଦୁଇଗୁଣରୁ ଦ୍ୱିତୀୟଟି ବିୟୋଗ କଲେ 12 ମିଳେ। ସହସମୀକରଣ ଗଢ଼ି ସଂଖ୍ୟାଦ୍ୱୟ ନିର୍ଣ୍ଣୟ କର ଓ ଉତ୍ତର ଯାଞ୍ଚ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୫, ଭାଗ ୨, ପ୍ରଶ୍ନ ୨a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ସଂଖ୍ୟାଦ୍ୱୟ x ଓ y ଧର। x + y = 15 ଏବଂ 2x − y = 12।
  2. ଯୋଗ କଲେ 3x = 27 ⇒ x = 9।
  3. ପ୍ରଥମ ସମୀକରଣରେ y = 15 − 9 = 6।
  4. ଯାଞ୍ଚରେ 9 + 6 = 15 ଏବଂ 2 × 9 − 6 = 12।

ପ୍ରଥମ 9 ଏବଂ ଦ୍ୱିତୀୟ 6।
