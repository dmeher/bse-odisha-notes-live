୧. ମୂଳଦ୍ୱୟର ସମଷ୍ଟି −5 ଓ ଗୁଣଫଳ 3 ହେଲେ ସମୀକରଣ ଗଠନ କର।

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ଏକକ ଅଗ୍ର ସହଗର ରୂପ x² − (α + β)x + αβ = 0।
  2. α + β = −5 ଓ αβ = 3 ବସାଇଲେ x² − (−5)x + 3 = 0।

x² + 5x + 3 = 0।

୨. x² − 5x + 6 = 0 ର ପ୍ରଭେଦକ ନିର୍ଣ୍ଣୟ କରି ମୂଳର ପ୍ରକୃତି ଲେଖ। ଦ୍ୱିଘାତ ସୂତ୍ରରେ ମୂଳ ନିର୍ଣ୍ଣୟ କରି ସମଷ୍ଟି ଓ ଗୁଣଫଳ ଯାଞ୍ଚ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୧a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. a = 1, b = −5, c = 6। ପ୍ରଭେଦକ D = 25 − 24 = 1 > 0।
  2. x = (−b ± √D)/(2a) = (5 ± 1)/2।
  3. ଯୋଗ ଚିହ୍ନରେ x = 3 ଓ ବିୟୋଗ ଚିହ୍ନରେ x = 2।
  4. ସମଷ୍ଟି 2 + 3 = 5 = −b/a। ଗୁଣଫଳ 2 × 3 = 6 = c/a।

ମୂଳ 2 ଓ 3, ଉଭୟ ବାସ୍ତବ ଓ ଭିନ୍ନ।

୩. ax² − 4x + (4a + 1) = 0 ର ମୂଳଦ୍ୱୟର ଗୁଣଫଳ 2। a ନିର୍ଣ୍ଣୟ କର। ପ୍ରାପ୍ତ ସମୀକରଣର ମୂଳଦ୍ୱୟର ସମଷ୍ଟି ଓ ପ୍ରକୃତି ଲେଖ।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୩a (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. a ≠ 0। ଗୁଣଫଳ = (4a + 1)/a = 2।
  2. 4a + 1 = 2a ⇒ a = −1/2।
  3. a ର ମାନ ରଖି ସମୀକରଣକୁ −2 ଦ୍ୱାରା ଗୁଣ କଲେ x² + 8x + 2 = 0।
  4. ସମଷ୍ଟି = −8, ପ୍ରଭେଦକ = 8² − 4 × 1 × 2 = 56 > 0।

a = −1/2; ମୂଳଦ୍ୱୟର ସମଷ୍ଟି −8 ଓ ମୂଳଦ୍ୱୟ ବାସ୍ତବ ଓ ଭିନ୍ନ।
