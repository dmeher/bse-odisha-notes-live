୧. ଦୁଇଟି ସୂକ୍ଷ୍ମକୋଣ A, B ପାଇଁ sin A = cos B ହେଲେ A + B କେତେ?

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. cos B = sin(90° − B)।
  2. ସେଥିରୁ sin A = sin(90° − B)। ଉଭୟ କୋଣ ସୂକ୍ଷ୍ମ ହେତୁ A = 90° − B।
  3. ଉଭୟ ପାର୍ଶ୍ୱରେ B ଯୋଗ କର।

A + B = 90°।

୨. ପାହାଡ଼ AB ଓ ତାହା ପାଖରେ ଏକ ସମତଳରେ ଥିବା ସ୍ତମ୍ଭ CD ମଧ୍ୟରେ AC ଭୂସମାନ୍ତର। ସ୍ତମ୍ଭର ଉଚ୍ଚତା CD = 100 ମି.। B ରୁ D ଓ C ପ୍ରତି କୌଣିକ ଅବନତି ଯଥାକ୍ରମେ 30° ଓ 60°। ପାହାଡ଼ର ଉଚ୍ଚତା ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫a (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. AB = h, AC = d ଧର। D ଦେଇ AC ସହ ସମାନ୍ତର ରେଖା AB କୁ Q ଠାରେ ଛେଦ କରୁ। BQ = h − 100 ଓ DQ = d।
  2. ଭୂସମାନ୍ତର ରେଖାଗୁଡ଼ିକ ସମାନ୍ତର ଥିବାରୁ tan 60° = h/d ଓ tan 30° = (h − 100)/d।
  3. ତେଣୁ h = √3d ଓ h − 100 = d/√3। ଦ୍ୱିତୀୟଟିକୁ 3 ଗୁଣ କଲେ 3(h − 100) = √3d = h।
  4. 3h − 300 = h ⇒ 2h = 300 ⇒ h = 150।

ପାହାଡ଼ର ଉଚ୍ଚତା 150 ମିଟର।

୩. 27 ମିଟର ଉଚ୍ଚ ବତୀଘରର ଶୀର୍ଷରୁ ଏକ ଜାହାଜର କୌଣିକ ଅବନତି 30°। ପାଦଦେଶରୁ ଜାହାଜର ଭୂସମାନ୍ତର ଦୂରତା ଓ ଶୀର୍ଷରୁ ଜାହାଜର ସରଳ ଦୂରତା ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. A ପାଦଦେଶ, B ଶୀର୍ଷ ଓ C ଜାହାଜ ନିଅ। BC ଦୃଷ୍ଟିରେଖା। ∠A = 90°।
  2. ଶୀର୍ଷର ଭୂସମାନ୍ତର ରେଖା ଓ AC ସମାନ୍ତର। ଏଣୁ ∠BCA = 30°।
  3. tan 30° = AB/AC = 27/AC ⇒ AC = 27√3।
  4. sin 30° = AB/BC = 27/BC ⇒ BC = 54।

ଭୂସମାନ୍ତର ଦୂରତା 27√3 ମିଟର ଓ ସରଳ ଦୂରତା 54 ମିଟର।

୪. ଗୋଟିଏ ସ୍ତମ୍ଭର ପାଦଦେଶକୁ ଧରି ଏକ ସରଳରେଖାରେ ସମାନ ପାର୍ଶ୍ୱରେ ଦୁଇ ବିନ୍ଦୁ ଅଛନ୍ତି। ଦୂର ବିନ୍ଦୁରୁ କୌଣିକ ଉନ୍ନତି 30°, ନିକଟ ବିନ୍ଦୁରୁ 60°। ବିନ୍ଦୁଦ୍ୱୟର ଦୂରତା 4 ମିଟର। ନିକଟ ବିନ୍ଦୁରୁ ପାଦଦେଶର ଦୂରତା ଓ ସ୍ତମ୍ଭର ଉଚ୍ଚତା ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୨, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫a (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ନିକଟ ଦୂରତା x, ଉଚ୍ଚତା h ଧର। ଦୂର ବିନ୍ଦୁରୁ ପାଦଦେଶ x + 4।
  2. ନିକଟ ତ୍ରିଭୁଜରେ h/x = tan 60° = √3।
  3. ଦୂର ତ୍ରିଭୁଜରେ h/(x + 4) = tan 30° = 1/√3।
  4. ଏଣୁ √3x = (x + 4)/√3 ⇒ 3x = x + 4 ⇒ x = 2। h = 2√3।

ନିକଟ ଦୂରତା 2 ମିଟର ଓ ଉଚ୍ଚତା 2√3 ମିଟର।

୫. ଯୋଗ ଓ ଅନ୍ତର କୋଣର ସୂତ୍ରରୁ sin(47°)cos(2°) − cos(47°)sin(2°) ଏବଂ cos(58°)cos(2°) − sin(58°)sin(2°) ର ମାନ ନିର୍ଣ୍ଣୟ କର। ପ୍ରଥମ ମାନର ବର୍ଗ ଓ ଦ୍ୱିତୀୟ ମାନର ଅନ୍ତର କେତେ?

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୨, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ପ୍ରଥମ ରାଶି sin A cos B − cos A sin B = sin(A − B) ସୂତ୍ରରେ ଅଛି।
  2. A = 47°, B = 2°। ଅନ୍ତର 45° ହେତୁ ପ୍ରଥମ ମାନ sin 45° = 1/√2।
  3. ଦ୍ୱିତୀୟ ରାଶି cos C cos D − sin C sin D = cos(C + D)।
  4. C = 58° ଓ D = 2° ର ଯୋଗ 60°। ଦ୍ୱିତୀୟ ମାନ cos 60° = 1/2।
  5. ଅନ୍ତର = (1/√2)² − 1/2 = 0।

ମାନ 1/√2 ଓ 1/2। ମାଗିଥିବା ଅନ୍ତର 0।

୬. ଭୂମି ସହ 60° କୋଣ କରି 12 ମିଟର ଲମ୍ବା ସିଡ଼ି କାନ୍ଥକୁ ଛୁଇଁଛି। କାନ୍ଥରେ ସ୍ପର୍ଶବିନ୍ଦୁର ଉଚ୍ଚତା ଓ କାନ୍ଥରୁ ପାଦର ଦୂରତା ନିର୍ଣ୍ଣୟ କର। ପିଥାଗୋରାସ୍ ସୂତ୍ରରେ ଯାଞ୍ଚ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୩, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫a (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ସିଡ଼ି କର୍ଣ୍ଣ = 12। କାନ୍ଥ ଓ ଭୂମି ପରସ୍ପର ପ୍ରତି ଲମ୍ବ।

  3. ଦୂରତା = 12 cos 60° = 6।
  4. ଯାଞ୍ଚରେ (6√3)² + 6² = 108 + 36 = 144 = 12²।

ଉଚ୍ଚତା 6√3 ମିଟର ଓ ଭୂସମାନ୍ତର ଦୂରତା 6 ମିଟର।

୯. ଯୋଗ ଓ ଅନ୍ତର କୋଣର ସୂତ୍ରରୁ sin(49°)cos(4°) − cos(49°)sin(4°) ଏବଂ cos(56°)cos(4°) − sin(56°)sin(4°) ର ମାନ ନିର୍ଣ୍ଣୟ କର। ପ୍ରଥମ ମାନର ବର୍ଗ ଓ ଦ୍ୱିତୀୟ ମାନର ଅନ୍ତର କେତେ?

ଉଚ୍ଚତା 10√3 ମିଟର ଓ ଭୂସମାନ୍ତର ଦୂରତା 10 ମିଟର।

୧୧. ଗୋଟିଏ ସ୍ତମ୍ଭର ପାଦଦେଶକୁ ଧରି ଏକ ସରଳରେଖାରେ ସମାନ ପାର୍ଶ୍ୱରେ ଦୁଇ ବିନ୍ଦୁ ଅଛନ୍ତି। ଦୂର ବିନ୍ଦୁରୁ କୌଣିକ ଉନ୍ନତି 30°, ନିକଟ ବିନ୍ଦୁରୁ 60°। ବିନ୍ଦୁଦ୍ୱୟର ଦୂରତା 10 ମିଟର। ନିକଟ ବିନ୍ଦୁରୁ ପାଦଦେଶର ଦୂରତା ଓ ସ୍ତମ୍ଭର ଉଚ୍ଚତା ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୫, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ନିକଟ ଦୂରତା x, ଉଚ୍ଚତା h ଧର। ଦୂର ବିନ୍ଦୁରୁ ପାଦଦେଶ x + 10।
  2. ନିକଟ ତ୍ରିଭୁଜରେ h/x = tan 60° = √3।
  3. ଦୂର ତ୍ରିଭୁଜରେ h/(x + 10) = tan 30° = 1/√3।
  4. ଏଣୁ √3x = (x + 10)/√3 ⇒ 3x = x + 10 ⇒ x = 5। h = 5√3।

ନିକଟ ଦୂରତା 5 ମିଟର ଓ ଉଚ୍ଚତା 5√3 ମିଟର।
