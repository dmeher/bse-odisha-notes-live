୧. P ରୁ ଅଙ୍କିତ ସ୍ପର୍ଶକଖଣ୍ଡ PQ ଓ PR ସମାନ ବୋଲି ପ୍ରମାଣ କର।

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. OQ ⟂ PQ ଓ OR ⟂ PR।
  2. △OQP ଓ △ORP ରେ OP ସାଧାରଣ କର୍ଣ୍ଣ, OQ = OR ଏକ ବୃତ୍ତର ବ୍ୟାସାର୍ଦ୍ଧ।
  3. ସମକୋଣ–କର୍ଣ୍ଣ–ବାହୁ ସର୍ତ୍ତରୁ ତ୍ରିଭୁଜଦ୍ୱୟ ସର୍ବସମ, ତେଣୁ ଅନୁରୂପ ବାହୁ PQ ଓ PR ସମାନ।

PQ = PR।

୨. ଏକ ବୃତ୍ତର ବହିଃସ୍ଥ ବିନ୍ଦୁରୁ ଅଙ୍କିତ ଦୁଇ ସ୍ପର୍ଶକଖଣ୍ଡ ସମାନ ବୋଲି ପ୍ରମାଣ କର। କେନ୍ଦ୍ରଗାମୀ ରଶ୍ମି ସ୍ପର୍ଶକ ଦୁଇଟି ମଧ୍ୟର କୋଣକୁ କିପରି ବିଭାଜନ କରେ ଦେଖାଅ।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୩b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. O କେନ୍ଦ୍ର ଓ P ବହିଃସ୍ଥ ବିନ୍ଦୁ ନିଅ। Q ଓ R ସ୍ପର୍ଶବିନ୍ଦୁ। OP, OQ, OR ଯୋଡ଼।
  2. OQ ⟂ PQ ଓ OR ⟂ PR। ତେଣୁ △OQP ଏବଂ △ORP ସମକୋଣୀ।
  3. OP ସାଧାରଣ କର୍ଣ୍ଣ ଓ OQ = OR ଏକେ ବୃତ୍ତର ବ୍ୟାସାର୍ଦ୍ଧ। ତେଣୁ ତ୍ରିଭୁଜଦ୍ୱୟ ସର୍ବସମ।
  4. ଅନୁରୂପ ବାହୁରୁ PQ = PR ଏବଂ ଅନୁରୂପ କୋଣରୁ ∠QPO = ∠OPR।

PQ = PR ଓ ∠QPO = ∠OPR।

୩. P ଠାରୁ ଦୁଇ ଛେଦକ ବୃତ୍ତକୁ P–A–B ଓ P–C–D କ୍ରମରେ ଛେଦ କରନ୍ତି। PA = 10, PB = 16, PD = 20 ସେ.ମି.। CD, AB ଓ P ରୁ ଅଙ୍କିତ ସ୍ପର୍ଶକଖଣ୍ଡର ଦୈର୍ଘ୍ୟ ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୪a (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. P ରୁ ଅଙ୍କିତ ସ୍ପର୍ଶକର ସ୍ପର୍ଶବିନ୍ଦୁ T ଧର। PT² = PA × PB = PC × PD।
  2. 10 × 16 = PC × 20 ⇒ PC = 8।
  3. CD = PD − PC = 20 − 8 = 12। AB = PB − PA = 16 − 10 = 6।
  4. PT² = 160 ⇒ PT = √160 = 4√10।

CD = 12, AB = 6, PT = 4√10 ସେ.ମି.।

୪. ବହିଃସ୍ଥ P ରୁ ଦୁଇ ଛେଦକରେ P–A–B ଓ P–C–D। PA = 2, PB = 32, PC = 4 ସେ.ମି.। PD, CD ଓ P ରୁ ଅଙ୍କିତ ସ୍ପର୍ଶକଖଣ୍ଡର ଦୈର୍ଘ୍ୟ ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୨, ଭାଗ ୨, ପ୍ରଶ୍ନ ୪a (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ଛେଦକର ସମ୍ପର୍କରୁ PA × PB = PC × PD; ବାମପାର୍ଶ୍ୱ = 64।
  2. PD = 64/4 = 16।
  3. CD = PD − PC = 16 − 4 = 12।
  4. PT² = PA × PB = 64 ⇒ PT = 8।

PD = 16, CD = 12, PT = 8 ସେ.ମି.।

୫. ଦତ୍ତ ବୃତ୍ତର P ବିନ୍ଦୁ ଦେଇ OP ବ୍ୟାସାର୍ଦ୍ଧ ପ୍ରତି ଅଙ୍କିତ ଲମ୍ବ ବୃତ୍ତର ସ୍ପର୍ଶକ ବୋଲି ପ୍ରମାଣ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୪, ଭାଗ ୨, ପ୍ରଶ୍ନ ୩b (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. O କେନ୍ଦ୍ର, OP = r। P ଦେଇ OP ପ୍ରତି ଲମ୍ବ ରେଖା L ଟାଣ।
  2. L ରେ P ଭିନ୍ନ ଯେକୌଣସି Q ନିଅ। △OPQ ରେ P କୋଣ ସମକୋଣ।
  3. OQ² = OP² + PQ² > OP²। ତେଣୁ OQ > r; Q ବୃତ୍ତର ବହିଃସ୍ଥ ବିନ୍ଦୁ।
  4. L ରେ ବୃତ୍ତର ସାଧାରଣ ବିନ୍ଦୁ କେବଳ P, ଏହି କାରଣରୁ L ସ୍ପର୍ଶକ।

ଲମ୍ବ ରେଖାଟି P ଠାରେ ବୃତ୍ତକୁ ସ୍ପର୍ଶ କରେ।

୬. ବହିଃସ୍ଥ P ରୁ ଦୁଇ ଛେଦକରେ P–A–B ଓ P–C–D। PA = 4, PB = 64, PC = 8 ସେ.ମି.। PD, CD ଓ P ରୁ ଅଙ୍କିତ ସ୍ପର୍ଶକଖଣ୍ଡର ଦୈର୍ଘ୍ୟ ନିର୍ଣ୍ଣୟ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୪, ଭାଗ ୨, ପ୍ରଶ୍ନ ୪a (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ଛେଦକର ସମ୍ପର୍କରୁ PA × PB = PC × PD; ବାମପାର୍ଶ୍ୱ = 256।
  2. PD = 256/8 = 32।
  3. CD = PD − PC = 32 − 8 = 24।
  4. PT² = PA × PB = 256 ⇒ PT = 16।

PD = 32, CD = 24, PT = 16 ସେ.ମି.।
