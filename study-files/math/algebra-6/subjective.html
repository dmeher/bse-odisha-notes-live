୧. A(3, 3), B(9, 0), C(12, 21) ଦ୍ୱାରା ଗଠିତ ତ୍ରିଭୁଜର କେଉଁ କୋଣ ସମକୋଣ?

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. AB² = 6² + (−3)² = 45; AC² = 9² + 18² = 405।
  2. BC² = 3² + 21² = 450। ତେଣୁ AB² + AC² = BC²।
  3. BC କର୍ଣ୍ଣ ହେବାରୁ ତାହାର ସମ୍ମୁଖ କୋଣ A ସମକୋଣ।

∠BAC = 90°।

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. AB² = (9 − 3)² + (0 − 3)² = 45। AC² = (12 − 3)² + (21 − 3)² = 405।
  2. BC² = (12 − 9)² + (21 − 0)² = 450।
  3. 45 + 405 = 450। ତେଣୁ ପିଥାଗୋରାସ୍ ଉପପାଦ୍ୟର ବିପରୀତ ଅନୁସାରେ ∠A ସମକୋଣ।
  4. AB = 3√5 ଓ AC = 9√5। କ୍ଷେତ୍ରଫଳ = AB × AC/2 = 67.5 ବର୍ଗ ଏକକ।

∠BAC = 90°, କ୍ଷେତ୍ରଫଳ 67.5 ବର୍ଗ ଏକକ।

  2. QR² = (5 − 8)² + (7 − 4)² = 18 ଓ SP² = (2 + 1)² + (−2 − 1)² = 18।
  3. ବିପରୀତ ବାହୁ ଯୋଡ଼ା ସମାନ, ତେଣୁ PQRS ସାମାନ୍ତରିକ ଚିତ୍ର।
  4. PR² = (5 − 2)² + (7 + 2)² = 90 = 72 + 18 = PQ² + QR²।
  5. ପିଥାଗୋରାସ୍ ଉପପାଦ୍ୟର ବିପରୀତରୁ ∠PQR = 90°। ଏକ କୋଣ ସମକୋଣ ହୋଇଥିବାରୁ ସାମାନ୍ତରିକଟି ଆୟତଚିତ୍ର।
