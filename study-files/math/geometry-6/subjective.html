  3. ସାଦୃଶ୍ୟରୁ AP/AB = 3/5। ତେଣୁ AP = 6.4 × 3/5, PB = 6.4 − AP।

୨. 6.4 ସେ.ମି. ରେଖାଖଣ୍ଡ AB ଅଙ୍କନ କର। 3 : 2 ଅନୁପାତରେ ଅନ୍ତର୍ବିଭାଜନ କରୁଥିବା ବିନ୍ଦୁ P ଅଙ୍କନ କରି ତୁମ ଅଙ୍କନର ଯଥାର୍ଥତା ଦର୍ଶାଅ।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. AB = 6.4 ସେ.ମି. ଅଙ୍କନ କର। A ଠାରୁ AB ସହ ସୂକ୍ଷ୍ମକୋଣ କରି ଗୋଟିଏ ରଶ୍ମି ଟାଣ।
  2. ରଶ୍ମିରେ ସମାନ କମ୍ପାସ ବ୍ୟବଧାନରେ କ୍ରମେ X₁, X₂, X₃, X₄ ଓ X₅ ଚିହ୍ନିତ କର।
  3. X₅B ଯୋଡ଼। X₃ ଦେଇ X₅B ସହ ସମାନ୍ତର ରେଖା ଟାଣ; ଏହା AB କୁ P ରେ ଛେଦ କରୁ।
  4. △AX₃P ∼ △AX₅B ରୁ AP/AB = AX₃/AX₅ = 3/5। ତେଣୁ PB/AB = 2/5 ଓ AP : PB = 3 : 2।
  5. ଯାଞ୍ଚ ପାଇଁ AP = 6.4 × 3/5 = 3.84 ଏବଂ PB = 6.4 − 3.84 = 2.56।

AP : PB = 3 : 2; ମାପରେ AP = 3.84 ଓ PB = 2.56 ସେ.ମି.।

୩. 3 ସେ.ମି. ବ୍ୟାସାର୍ଦ୍ଧର ବୃତ୍ତ ଅଙ୍କନ କରି ତାହାର ଏକ ବିନ୍ଦୁ P ଠାରେ ସ୍ପର୍ଶକ ଅଙ୍କନ କର। ଅନ୍ୟ ବୃତ୍ତସ୍ଥ ବିନ୍ଦୁଠାରେ ଏହି ରେଖା ବୃତ୍ତକୁ ଛେଦ କରିପାରିବ ନାହିଁ କାହିଁକି?

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୨, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫b (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. O ଚିହ୍ନି 3 ସେ.ମି. କମ୍ପାସ ବିସ୍ତାରରେ ବୃତ୍ତ ଅଙ୍କନ କର। ବୃତ୍ତରେ P ନିଅ ଓ OP ଯୋଡ଼।
  2. OP ରେ ଓ ଏହାର ବର୍ଦ୍ଧିତ ଅଂଶରେ P ଠାରୁ ସମାନ ଦୂରରେ U ଓ V ଚିହ୍ନିତ କର।
  3. U ଓ V କେନ୍ଦ୍ର କରି ସମାନ ବ୍ୟାସାର୍ଦ୍ଧରେ ଚାପ କାଟି ରେଖାର ଏକ ପାର୍ଶ୍ୱରେ ଛେଦବିନ୍ଦୁ S ନିଅ। PS ଟାଣ। ଏହା OP ପ୍ରତି ଲମ୍ବ।
  4. PS ଉପରେ P ଭିନ୍ନ Q ନେଲେ OQ² = OP² + PQ² > OP², ତେଣୁ Q ବୃତ୍ତ ବାହାରେ।

P ଦେଇ OP ପ୍ରତି ଲମ୍ବ ରେଖା ହିଁ ଆବଶ୍ୟକ ସ୍ପର୍ଶକ।

୪. 4 ସେ.ମି. ବାହୁବିଶିଷ୍ଟ ABCD ବର୍ଗଚିତ୍ରର ପରିବୃତ୍ତ ଓ ଅନ୍ତଃବୃତ୍ତ ଅଙ୍କନ କର। ଏମାନଙ୍କ କେନ୍ଦ୍ର ଓ ବ୍ୟାସାର୍ଦ୍ଧ ଲେଖ।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୨, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. AB = 4 ସେ.ମି. ନେଇ A ଓ B ଠାରେ ଏକେ ପାର୍ଶ୍ୱକୁ ଲମ୍ବ ଟାଣ। AD = BC = 4 ସେ.ମି. ନେଇ CD ଯୋଡ଼।
  2. AC ଓ BD ଟାଣି ଛେଦବିନ୍ଦୁ O ନିଅ। ଦୁଇ କର୍ଣ୍ଣ ସମାନ ଓ ପରସ୍ପରକୁ ସମଦ୍ୱିଖଣ୍ଡ କରନ୍ତି, ତେଣୁ OA = OB = OC = OD।
  3. O କେନ୍ଦ୍ର, OA ବ୍ୟାସାର୍ଦ୍ଧରେ ପରିବୃତ୍ତ ଅଙ୍କନ କର। AC = √(4² + 4²) = 4√2; OA ତାହାର ଅର୍ଦ୍ଧ।
  4. O ରୁ AB କୁ OM ଲମ୍ବ ଟାଣ। OM = 2 ସେ.ମି.। O ରୁ ଚାରି ବାହୁର ଦୂରତା ସମାନ ହେତୁ O କେନ୍ଦ୍ର ଓ OM ବ୍ୟାସାର୍ଦ୍ଧରେ ଅନ୍ତଃବୃତ୍ତ ଅଙ୍କନ କର।

ଦୁଇ ବୃତ୍ତର କେନ୍ଦ୍ର O। ପରିବୃତ୍ତର ବ୍ୟାସାର୍ଦ୍ଧ 2√2 ଓ ଅନ୍ତଃବୃତ୍ତର ବ୍ୟାସାର୍ଦ୍ଧ 2 ସେ.ମି.।

୫. 7.5 ସେ.ମି. ଦୈର୍ଘ୍ୟର PQ କୁ 4 : 3 ଅନୁପାତରେ ଅନ୍ତର୍ବିଭାଜନ କର। ଦୁଇ ଖଣ୍ଡକୁ ବାହୁ ଭାବେ ନେଇ ଏକ ଆୟତଚିତ୍ର ଅଙ୍କନ କର।

  2. ସପ୍ତମ ବିନ୍ଦୁକୁ Q ସହ ଯୋଡ଼। ଚତୁର୍ଥ ବିନ୍ଦୁ ଦେଇ ଏହା ସହ ସମାନ୍ତର ଟାଣି PQ କୁ T ରେ ଛେଦ କର। PT : TQ = 4 : 3।

  4. ଚାରି କୋଣ ସମକୋଣ। ବାହୁ ଦୁଇଟି 7.5 × 4/7 ଓ 7.5 × 3/7।

ଆୟତଚିତ୍ରର ବାହୁ 30/7 ଓ 22.5/7 ସେ.ମି.।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୪, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

୯. 2 ସେ.ମି. ବ୍ୟାସାର୍ଦ୍ଧର ବୃତ୍ତ ଚାରିପଟେ ଏକ ସମବାହୁ ତ୍ରିଭୁଜ ଅଙ୍କନ କର ଯାହାର ପ୍ରତି ବାହୁ ବୃତ୍ତକୁ ସ୍ପର୍ଶ କରିବ।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୫, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫b (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. O କେନ୍ଦ୍ରରେ ଦତ୍ତ ବୃତ୍ତ ଅଙ୍କନ କର। କମ୍ପାସର ବିସ୍ତାର ବ୍ୟାସାର୍ଦ୍ଧ ସମାନ ରଖି ପରିଧିରେ କ୍ରମେ ଛଅ ସମାନ ଚାପ କାଟ।
  2. ଗୋଟିଏ ଛାଡ଼ି ଗୋଟିଏ ବିନ୍ଦୁ X, Y, Z ନିଅ। ଅନୁକ୍ରମିକ ବ୍ୟାସାର୍ଦ୍ଧ ମଧ୍ୟର କୋଣ 120°।
  3. X, Y, Z ଠାରେ ସଂପୃକ୍ତ ବ୍ୟାସାର୍ଦ୍ଧ ପ୍ରତି ଲମ୍ବ ଟାଣ। ସେଗୁଡ଼ିକ ସ୍ପର୍ଶକ।
  4. ପ୍ରତ୍ୟେକ ଦୁଇ ସଂଲଗ୍ନ ସ୍ପର୍ଶକ ମଧ୍ୟର ଅନ୍ତଃକୋଣ 180° − 120° = 60°। ତେଣୁ ତିନି ଛେଦବିନ୍ଦୁର ତ୍ରିଭୁଜ ସମବାହୁ।

ତିନୋଟି କ୍ରମାଗତ ସ୍ପର୍ଶକର ଛେଦବିନ୍ଦୁ ମିଶି ସମବାହୁ ତ୍ରିଭୁଜ ଗଠନ କରନ୍ତି।

୧୦. 6 ସେ.ମି. ଦୀର୍ଘ BC ଓ ∠A = 45° ହେବା ପାଇଁ △ABC ର ପରିବୃତ୍ତ ଅଙ୍କନ କର। ଚିତ୍ରରେ ଗୋଟିଏ ଉପଯୁକ୍ତ A ଦେଖାଅ ଓ କୋଣର ମାନ ଯାଞ୍ଚ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୫, ଭାଗ ୨, ପ୍ରଶ୍ନ ୫b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. BC = 6 ସେ.ମି. ଅଙ୍କନ କର। ଏହାର ସମଦ୍ୱିଖଣ୍ଡକ ଲମ୍ବ ଟାଣ।
  2. B ଠାରେ BC ସହ 45° କୋଣ କରି ରଶ୍ମି ଟାଣ। ସମଦ୍ୱିଖଣ୍ଡକ ଲମ୍ବ ସହ ଛେଦବିନ୍ଦୁ O ନିଅ।
  3. OB = OC, ତେଣୁ ∠OBC = ∠OCB = 45° ଓ ∠BOC = 90°।
  4. O କେନ୍ଦ୍ର ଓ OB ବ୍ୟାସାର୍ଦ୍ଧରେ ବୃତ୍ତ ଅଙ୍କନ କର। ଦୀର୍ଘ ଚାପ BC ରେ B, C ଭିନ୍ନ ବିନ୍ଦୁ A ନେଇ AB, AC ଯୋଡ଼। ସଂପୃକ୍ତ ଚାପର ଡିଗ୍ରୀ ପରିମାପ 90° ହେତୁ ∠BAC = 45°।

ଦୀର୍ଘ ଚାପରେ A ବାଛିଲେ ∠BAC = 45°।
