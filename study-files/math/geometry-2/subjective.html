୧. ତ୍ରିଭୁଜର ପରିକେନ୍ଦ୍ର ନିର୍ଣ୍ଣୟ ପାଇଁ ତ୍ରିଭୁଜର ଦୁଇ ବାହୁର ସମଦ୍ୱିଖଣ୍ଡକ ଲମ୍ବ କାହିଁକି ଯଥେଷ୍ଟ?

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. AB ର ସମଦ୍ୱିଖଣ୍ଡକ ଲମ୍ବ ଉପରେ O ଥିଲେ OA = OB।
  2. BC ର ସମଦ୍ୱିଖଣ୍ଡକ ଲମ୍ବ ଉପରେ ମଧ୍ୟ O ଥିଲେ OB = OC।
  3. ତେଣୁ O କୁ କେନ୍ଦ୍ର ଓ OA କୁ ବ୍ୟାସାର୍ଦ୍ଧ ନେଲେ ସେହି ବୃତ୍ତ ତିନି ଶୀର୍ଷ ଦେଇ ଯାଏ।

ଲମ୍ବଦ୍ୱୟର ଛେଦବିନ୍ଦୁ ତିନି ଶୀର୍ଷରୁ ସମଦୂରବର୍ତ୍ତୀ।

୨. ଏକ ସରଳରେଖାରେ ନଥିବା ତିନୋଟି ବିନ୍ଦୁ ଦେଇ ଗୋଟିଏ ଓ କେବଳ ଗୋଟିଏ ବୃତ୍ତ ଅଙ୍କନ କରାଯାଇପାରିବ ବୋଲି ପ୍ରମାଣ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୩b (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. ଦତ୍ତ ଅଣସରଳରେଖୀ ବିନ୍ଦୁ A, B, C କୁ ଯୋଡ଼। AB ଓ BC ର ସମଦ୍ୱିଖଣ୍ଡକ ଲମ୍ବଦ୍ୱୟ ଅଙ୍କନ କର।
  2. AB ଓ BC ସମାନ୍ତର ନୁହନ୍ତି, ତେଣୁ ଲମ୍ବଦ୍ୱୟ ଗୋଟିଏ ବିନ୍ଦୁ O ଠାରେ ଛେଦ କରିବେ।
  3. O ପ୍ରଥମ ଲମ୍ବରେ ଥିବାରୁ OA = OB। ଦ୍ୱିତୀୟ ଲମ୍ବରେ ଥିବାରୁ OB = OC। O କେନ୍ଦ୍ର, OA ବ୍ୟାସାର୍ଦ୍ଧର ବୃତ୍ତ ତିନି ବିନ୍ଦୁ ଦେଇ ଯାଏ।
  4. ଅନ୍ୟ କୌଣସି ଏପରି ବୃତ୍ତର କେନ୍ଦ୍ର ମଧ୍ୟ ତିନି ବିନ୍ଦୁରୁ ସମଦୂରବର୍ତ୍ତୀ ହେବା ଦରକାର। ତେଣୁ ଉଭୟ ଲମ୍ବ ଉପରେ ରହିବ।
  5. ଦୁଇ ଲମ୍ବର ଛେଦବିନ୍ଦୁ କେବଳ O। ତେଣୁ କେନ୍ଦ୍ର ଓ ବ୍ୟାସାର୍ଦ୍ଧ ଏକମାତ୍ର।

ବୃତ୍ତର ଅସ୍ତିତ୍ୱ ଓ ଏକମାତ୍ରତା ସିଦ୍ଧ।

୩. ବୃତ୍ତର କେନ୍ଦ୍ରରୁ ବ୍ୟାସ ଭିନ୍ନ ଏକ ଜ୍ୟା ପ୍ରତି ଅଙ୍କିତ ଲମ୍ବ ଜ୍ୟାକୁ ସମଦ୍ୱିଖଣ୍ଡ କରେ ବୋଲି ପ୍ରମାଣ କର। ଚିତ୍ରରେ କେନ୍ଦ୍ର, ଜ୍ୟା ଓ ଲମ୍ବପାଦ ଚିହ୍ନିତ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୨, ଭାଗ ୨, ପ୍ରଶ୍ନ ୩b (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. O କେନ୍ଦ୍ର, AB ଜ୍ୟା ଓ M ଲମ୍ବପାଦ ଧର। OA ଓ OB ଯୋଡ଼।
  2. △OMA ଓ △OMB ରେ ∠OMA = ∠OMB = 90°। OA = OB ବ୍ୟାସାର୍ଦ୍ଧ ଓ OM ସାଧାରଣ ବାହୁ।
  3. କର୍ଣ୍ଣ ଓ ଏକ ଅନୁରୂପ ବାହୁ ସମାନ ହେତୁ ସମକୋଣୀ ତ୍ରିଭୁଜଦ୍ୱୟ ସର୍ବସମ।
  4. ଅନୁରୂପ ବାହୁରୁ AM = MB।

AM = MB।

୪. ଅର୍ଦ୍ଧବୃତ୍ତରେ ଅନ୍ତର୍ଲିଖିତ କୋଣ ଏକ ସମକୋଣ ବୋଲି ପ୍ରମାଣ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୨, ଭାଗ ୨, ପ୍ରଶ୍ନ ୩b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. BC ବ୍ୟାସ, O କେନ୍ଦ୍ର ଓ A ଅର୍ଦ୍ଧବୃତ୍ତର B, C ଭିନ୍ନ ଏକ ବିନ୍ଦୁ। OA ଯୋଡ଼।
  2. OA = OB ହେତୁ ∠OAB = ∠ABO। OA = OC ହେତୁ ∠OAC = ∠ACO।
  3. ତେଣୁ ∠BAC = ∠OAB + ∠OAC = ∠ABC + ∠ACB।
  4. △ABC ର ତିନି କୋଣର ସମଷ୍ଟି 180°। ଏଣୁ 2∠BAC = 180°।

ବ୍ୟାସ BC ଉପରେ ଅନ୍ତର୍ଲିଖିତ ∠BAC = 90°।

୫. ଏକ ବୃତ୍ତର ସମାନ ଜ୍ୟା କେନ୍ଦ୍ରରେ ସମାନ କୋଣ ଉତ୍ପନ୍ନ କରେ ବୋଲି ଦର୍ଶାଅ। ଏହାର ବିପରୀତ କଥନ ମଧ୍ୟ ପ୍ରମାଣ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୩, ଭାଗ ୨, ପ୍ରଶ୍ନ ୩b (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. AB ଓ CD ଜ୍ୟାର ପ୍ରାନ୍ତଗୁଡ଼ିକୁ କେନ୍ଦ୍ର O ସହ ଯୋଡ଼।
  2. OA = OC, OB = OD ବ୍ୟାସାର୍ଦ୍ଧ। ଯଦି AB = CD, ତେବେ ତିନି ବାହୁ ସମାନ ହେତୁ △OAB ≅ △OCD।
  3. ଅନୁରୂପ କୋଣରୁ ∠AOB = ∠COD।
  4. ଓଲଟା ଦିଗରେ ଏହି କୋଣଦ୍ୱୟ ସମାନ ଦିଆଥିଲେ ଦୁଇ ବାହୁ ଓ ଅନ୍ତର୍ଗତ କୋଣ ଦ୍ୱାରା ତ୍ରିଭୁଜଦ୍ୱୟ ସର୍ବସମ। ତେଣୁ AB = CD।

AB = CD ଓ ∠AOB = ∠COD ପରସ୍ପର ସମତୁଲ।

୬. 15 ସେ.ମି. ବ୍ୟାସାର୍ଦ୍ଧର ଏକ ବୃତ୍ତରେ ଦୁଇ ଭିନ୍ନ ସମାନ୍ତର ଜ୍ୟା ପ୍ରତ୍ୟେକ 24 ସେ.ମି.। ଉଭୟ ଜ୍ୟା ମଧ୍ୟର ଦୂରତା ନିର୍ଣ୍ଣୟ କର ଓ ସେମାନେ କେନ୍ଦ୍ରର ଭିନ୍ନ ପାର୍ଶ୍ୱରେ କାହିଁକି ଅଛନ୍ତି ବୁଝାଅ।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୩, ଭାଗ ୨, ପ୍ରଶ୍ନ ୪a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. କେନ୍ଦ୍ରରୁ ପ୍ରତ୍ୟେକ ଜ୍ୟାକୁ ଲମ୍ବ ଟାଣ। ଲମ୍ବ ଜ୍ୟାକୁ ସମଦ୍ୱିଖଣ୍ଡ କରେ, ଅର୍ଦ୍ଧଜ୍ୟା = 12।
  2. ଲମ୍ବର ଦୈର୍ଘ୍ୟ = √(15² − 12²) = 9। ଉଭୟ ଜ୍ୟା ପାଇଁ ଏହି ଦୂରତା ଏକ।
  3. ଏକ ପାର୍ଶ୍ୱରେ ସମାନ ଦୂରତାରେ ସମାନ୍ତର ଜ୍ୟାଦ୍ୱୟ ଥିଲେ ଏକେ ରେଖାରେ ମିଶିଯିବେ। ତେଣୁ ଭିନ୍ନ ଜ୍ୟାଦ୍ୱୟ ଦୁଇ ପାର୍ଶ୍ୱରେ।
  4. ମଧ୍ୟବର୍ତ୍ତୀ ଦୂରତା = 9 + 9 = 18।

ଦୂରତା 18 ସେ.ମି.।

୭. ବୃତ୍ତାନ୍ତର୍ଲିଖିତ ABCD ର ବିପରୀତ କୋଣଦ୍ୱୟର ସମଷ୍ଟି 180° ବୋଲି ପ୍ରମାଣ କର।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୪, ଭାଗ ୨, ପ୍ରଶ୍ନ ୩b · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. A, B, C, D କୁ ଏହି କ୍ରମରେ ବୃତ୍ତରେ ନିଅ। ∠ABC ଚାପ ADC ଉପରେ ଓ ∠ADC ଚାପ ABC ଉପରେ ଅଛି।
  2. ପ୍ରତ୍ୟେକ ବୃତ୍ତସ୍ଥ କୋଣ ତାହାର ସଂପୃକ୍ତ ଚାପର ଡିଗ୍ରୀ ପରିମାପର ଅର୍ଦ୍ଧ।
  3. ଦୁଇ ଚାପର ପରିମାପର ସମଷ୍ଟି 360°। ତେଣୁ ଦୁଇ କୋଣର ସମଷ୍ଟି 180°।
  4. ଅନ୍ୟ ଦୁଇ ବିପରୀତ କୋଣ ପାଇଁ ବି B ଓ D ମଧ୍ୟର ଦୁଇ ଚାପ ମିଶି ସମଗ୍ର ବୃତ୍ତ ହୁଏ। ଏଣୁ ସେମାନଙ୍କ ସମଷ୍ଟି ମଧ୍ୟ 180°।

∠ABC + ∠ADC = 180° ଓ ∠BAD + ∠BCD = 180°।

୮. ବୃତ୍ତର ଏକ ଜ୍ୟାର ମଧ୍ୟବିନ୍ଦୁ ଓ କେନ୍ଦ୍ର ଭିନ୍ନ ହେଲେ ସେମାନଙ୍କ ସଂଯୋଜକ ରେଖା ଜ୍ୟା ପ୍ରତି ଲମ୍ବ ବୋଲି ପ୍ରମାଣ କର।

୯. 25 ସେ.ମି. ବ୍ୟାସାର୍ଦ୍ଧର ଏକ ବୃତ୍ତରେ ଦୁଇ ଭିନ୍ନ ସମାନ୍ତର ଜ୍ୟା ପ୍ରତ୍ୟେକ 40 ସେ.ମି.। ଉଭୟ ଜ୍ୟା ମଧ୍ୟର ଦୂରତା ନିର୍ଣ୍ଣୟ କର ଓ ସେମାନେ କେନ୍ଦ୍ରର ଭିନ୍ନ ପାର୍ଶ୍ୱରେ କାହିଁକି ଅଛନ୍ତି ବୁଝାଅ।

ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୫, ଭାଗ ୨, ପ୍ରଶ୍ନ ୪a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

  4. ମଧ୍ୟବର୍ତ୍ତୀ ଦୂରତା = 15 + 15 = 30।
