୨୦୨୪ Set D ଓ ୨୦୨୬ Set Bରେ ମୂଳ ବୀଜଗଣିତ ୨୨, ସଡ଼କ ସୁରକ୍ଷା ୨ ଓ ଜ୍ୟାମିତି ୨୬ଟି MCQ ଥିଲା। ୨୦୨୫ Set Aରେ ଏହି ଗଣନା ଯଥାକ୍ରମେ ୨୩, ୨ ଓ ୨୫। ଅଭ୍ୟାସ ସେଟ୍‌ରେ ଦିଆଯାଇଥିବା ବହିର ପାଠଗୁଡ଼ିକୁ ନିଆଯାଇଛି।

  • ପ୍ରଶ୍ନ ୪ରେ ବୃତ୍ତର ଚିତ୍ରରୁ କୋଣ ନିର୍ଣ୍ଣୟ କରିବାକୁ ହୁଏ। ପ୍ରଶ୍ନ ୫ରେ ସଦୃଶ ତ୍ରିଭୁଜର ଅନୁରୂପ ବାହୁ ଚିହ୍ନି ଚାରିଟି ସମ୍ପର୍କ ମଧ୍ୟରୁ ଭୁଲଟି ବାଛିବାକୁ ହୁଏ।
