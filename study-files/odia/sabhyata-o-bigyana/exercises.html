ମୁଦ୍ରିତ ପ୍ରଶ୍ନ ୧–୩୦। ଯାଞ୍ଚ କରାଯାଇଥିବା ଉତ୍ତର ପ୍ରଶ୍ନକ୍ରମରେ ଦିଆଯାଇଛି।

୨୮ରେ ଅନ୍ୟ ବିଜ୍ଞାନ ପ୍ରବନ୍ଧ ପାଠ ଆବଶ୍ୟକ। ମୂଳ ଅଧ୍ୟାୟର ଲେଖକ ପରିଚୟରୁ ପତ୍ରିକା ଓ ରଚନା ସନ୍ଧାନର ସୂତ୍ର ଦିଆଯାଇଛି।

୧. ଆଠଟି ଶବ୍ଦର ବିପରୀତାର୍ଥ ଲେଖ।

ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ବିପରୀତ ପଦରେ କେଉଁ ଭାବଟି ଓଲଟିଲା ଦେଖ। ନୈତିକ–ଅନୈତିକରେ ନୀତି, ଇଚ୍ଛାକୃତ–ଅନିଚ୍ଛାକୃତରେ ଇଚ୍ଛା ଓ ଅକ୍ଷୁଣ୍ଣ–କ୍ଷୁଣ୍ଣରେ ଅକ୍ଷତ ରହିବାର ଭାବ।
  2. ପ୍ରାଚୀନ–ଆଧୁନିକ ଓ ପୂର୍ବବର୍ତ୍ତୀ–ପରବର୍ତ୍ତୀ ଯୋଡ଼ାରେ ସମୟର ପାର୍ଥକ୍ୟ। ଉନ୍ନତି–ଅବନତିରେ ଉତ୍ଥାନ ଓ ପତନ, ବିକାଶ–ସଙ୍କୋଚରେ ପ୍ରସାର ଓ ସଙ୍କୁଚନ, ସଂଯୋଗ–ବିଯୋଗରେ ମିଳିବା ଓ ଅଲଗା ହେବାର ଭାବ।

ଉତ୍ତର

ନୈତିକ — ଅନୈତିକ। ଉନ୍ନତି — ଅବନତି।

ପ୍ରାଚୀନ — ଆଧୁନିକ। ଇଚ୍ଛାକୃତ — ଅନିଚ୍ଛାକୃତ।

ଅକ୍ଷୁଣ୍ଣ — କ୍ଷୁଣ୍ଣ। ପୂର୍ବବର୍ତ୍ତୀ — ପରବର୍ତ୍ତୀ।

ବିକାଶ — ସଙ୍କୋଚ। ସଂଯୋଗ — ବିଯୋଗ।

୨. ସାତଟି ଶବ୍ଦକୁ ବାକ୍ୟରେ ପ୍ରୟୋଗ କର।

ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ନମୁନା ବାକ୍ୟରେ ‘ବୈଷୟିକ’ ବାହ୍ୟ ଜୀବନର ସୁଖକୁ ଓ ‘ମାନବିକତା’ ମଣିଷ ପ୍ରତି ସ୍ନେହ ଓ କର୍ତ୍ତବ୍ୟକୁ ବୁଝାଏ। ଏହି ଦୁଇ ଧାରଣାର ସମ୍ପର୍କ ପ୍ରବନ୍ଧର ଆଲୋଚ୍ୟ।
  2. ଆରୋହଣରେ ଉପରକୁ ଚଢ଼ିବା, ଅନବରତରେ ଲଗାତାର ଚାଲିବା, ଦୁରୂହରେ କଠିନତା, ବିସ୍ତୃତରେ ପ୍ରସାର ଓ ବିଚଳିତରେ ଅସ୍ଥିର ହେବାର ଭାବ ରଖ। ତେବେ ଶବ୍ଦ ବଦଳାଇ ପଢ଼ିଲେ ମଧ୍ୟ ମୂଳ ଅର୍ଥ ମେଳ ଖାଇବ।

ଉତ୍ତର

ନମୁନା ବାକ୍ୟ — ରେଳ ଓ ମଟର ଆମକୁ ବୈଷୟିକ ସୁଖ ଦିଅନ୍ତି। ମାନବିକତା ଆଧୁନିକ ସଭ୍ୟତାର ଏକ ଆଦର୍ଶ।

ମଣିଷ ଉଚ୍ଚ ପର୍ବତ ଆରୋହଣ କରେ। ସତ୍ୟର ଅନୁସନ୍ଧାନ ଅନବରତ ଚାଲିଛି।

ବିଜ୍ଞାନ ଦୁରୂହ ସମସ୍ୟାକୁ ସହଜ କରେ। ଅଧ୍ୟୟନରେ ଜ୍ଞାନର ସୀମା ବିସ୍ତୃତ ହୁଏ।

ବାଧା ଆସିଲେ ଅନୁସନ୍ଧାନୀ ବିଚଳିତ ହୁଏନି।

୩. ଛଅଟି ଶବ୍ଦର ସନ୍ଧିବିଚ୍ଛେଦ କର।

ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ଦୁଇ ମୂଳ ଭାଗର ସୀମା ଚିହ୍ନ। ଅନ୍ୟ + ଅନ୍ୟରେ ସନ୍ଧିସ୍ଥଳରେ ଦୀର୍ଘ ‘ଆ’ ମିଳେ। ସମ୍ + ଯୋଗରେ ଅନ୍ତିମ ମ୍ ସ୍ଥାନରେ ଅନୁସ୍ୱାର ଦିଶେ।
  2. ଅନ୍ତଃ, ଆୟୁଃ ଓ ମନଃର ଅନ୍ତିମ ବିସର୍ଗ ପରପଦ ସହ ମିଶି କ୍ରମେ ଅନ୍ତର୍ଗତ, ଆୟୁର୍ବେଦ ଓ ମନସ୍ତତ୍ତ୍ୱ ହୋଇଛି। ଉଲ୍ଲିଖିତର ‘ଲ୍ଲ’କୁ ପୃଥକ୍ କଲେ ଉତ୍ + ଲିଖିତ ମିଳେ।

ଉତ୍ତର

ଅନ୍ୟାନ୍ୟ = ଅନ୍ୟ + ଅନ୍ୟ। ଅନ୍ତର୍ଗତ = ଅନ୍ତଃ + ଗତ।

ସଂଯୋଗ = ସମ୍ + ଯୋଗ। ଆୟୁର୍ବେଦ = ଆୟୁଃ + ବେଦ।

ମନସ୍ତତ୍ତ୍ୱ = ମନଃ + ତତ୍ତ୍ୱ। ଉଲ୍ଲିଖିତ = ଉତ୍ + ଲିଖିତ।

୪. ନଅଟି ଶବ୍ଦର ପ୍ରକୃତି ଓ ପ୍ରତ୍ୟୟ ଦିଅ।

ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ଏକା ପ୍ରତ୍ୟୟ ଥିବା ପଦକୁ ମିଳାଅ। ପାର୍ବତୀୟ ଓ ଭାରତୀୟରେ ‘ଈୟ’, ଶାରୀରିକ, ମାନସିକ ଓ ବୈଜ୍ଞାନିକରେ ‘ଇକ’। ପ୍ରତ୍ୟୟ ଯୋଗ ହେଲେ ପ୍ରକୃତିର ସ୍ୱର ମଧ୍ୟ ବଦଳିପାରେ।
  2. କରଣୀୟ ଓ କର୍ତ୍ତବ୍ୟର ପ୍ରକୃତି ଏକ—‘କୃ’। କିନ୍ତୁ ‘ଅନୀୟ’ ଓ ‘ତବ୍ୟ’ ପ୍ରତ୍ୟୟ ଅଲଗା। ‘ତ୍ୟାଗ’ର ମୂଳ ଧାତୁ ‘ତ୍ୟଜ୍’ ଓ ‘ସର୍ବାଙ୍ଗୀନ’ର ମୂଳ ‘ସର୍ବାଙ୍ଗ’ ଚିହ୍ନିଲେ ଶେଷର ଯୋଗକୁ ସହଜରେ ଅଲଗା କରିହୁଏ।

ଉତ୍ତର

ଶାରୀରିକ = ଶରୀର + ଇକ। ମାନସିକ = ମନସ୍ + ଇକ।

ପାର୍ବତୀୟ = ପର୍ବତ + ଈୟ। ଭାରତୀୟ = ଭାରତ + ଈୟ।

ତ୍ୟାଗ = ତ୍ୟଜ୍ + ଅ। ସର୍ବାଙ୍ଗୀନ = ସର୍ବାଙ୍ଗ + ଈନ।

କରଣୀୟ = କୃ + ଅନୀୟ। ବୈଜ୍ଞାନିକ = ବିଜ୍ଞାନ + ଇକ।

କର୍ତ୍ତବ୍ୟ = କୃ + ତବ୍ୟ।

୫. ଚାରିଟି ଶବ୍ଦର ଦୁଇଟି ଲେଖାଏଁ ପ୍ରତିଶବ୍ଦ ଦିଅ।

ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ପ୍ରଥମେ ପଦ କାହାକୁ ବୁଝାଉଛି ଦେଖ। ହସ୍ତୀ, ଗଜ ଓ କରୀ ଏକ ପ୍ରାଣୀକୁ; ମାନବ, ନର ଓ ମନୁଷ୍ୟ ମଣିଷକୁ ସୂଚାନ୍ତି।
  2. ପ୍ରସଙ୍ଗରେ ବସାଇ ପରଖ। ‘ମୈତ୍ରୀର ଧ୍ୱଜା’ରେ ଧ୍ୱଜା ସ୍ଥାନରେ ପତାକା ବା କେତନ ରଖିଲେ ପ୍ରତୀକଟି ରହେ। ହିମାଳୟ ପାଇଁ ଗିରି ବା ଶୈଳ କହିଲେ ପର୍ବତର ପରିଚୟ ରହେ।

ଉତ୍ତର

ହସ୍ତୀ — ଗଜ, କରୀ। ମାନବ — ନର, ମନୁଷ୍ୟ।

ଧ୍ୱଜା — ପତାକା, କେତନ। ପର୍ବତ — ଗିରି, ଶୈଳ।

୬. ଦିଆଯାଇଥିବା ଚାରୋଟି ଅଶୁଦ୍ଧ ଶବ୍ଦ ସଂଶୋଧନ କର।

ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ‘ଶରୀର’ରୁ ‘ଶାରୀରିକ’ ହେଉଛି। ‘ସାହାଯ୍ୟ’ ଶେଷରେ ଯୁକ୍ତାକ୍ଷର ‘ଯ୍ୟ’ ଓ ‘ଆଶୀର୍ବାଦ’ରେ ଦୀର୍ଘ ‘ଈ’ ପ୍ରତି ଧ୍ୟାନ ଦିଅ।

ଉତ୍ତର

କ୍ରମ ଅନୁସାରେ ଶୁଦ୍ଧ ରୂପ — ଶାରୀରିକ, ସାହାଯ୍ୟ, ସଂଶ୍ଳିଷ୍ଟ, ଆଶୀର୍ବାଦ।

୭. ଲକ୍ଷ–ଲକ୍ଷ୍ୟ, କୁଳ–କୂଳ ଓ ଚରିତ–ଚରିତ୍ରର ଅର୍ଥଭେଦ ଦର୍ଶାଅ।

ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ଯାଞ୍ଚ ପାଇଁ ନମୁନା ବାକ୍ୟ ନିଅ—“ଲକ୍ଷ ଲୋକଙ୍କ ଲକ୍ଷ୍ୟ ଏକ।” ପ୍ରଥମ ପଦ ସଂଖ୍ୟା, ଦ୍ୱିତୀୟଟି ଉଦ୍ଦେଶ୍ୟ। “ନଦୀକୂଳରେ ମୋର କୁଳ ବସବାସ କରେ”ରେ ସ୍ଥାନ ଓ ବଂଶ ଭିନ୍ନ।
  2. “ତାଙ୍କ ଚରିତ ପଢ଼ି ତାଙ୍କ ଚରିତ୍ରର ପରିଚୟ ପାଇଲି”ରେ ପ୍ରଥମଟି ଜୀବନବୃତ୍ତାନ୍ତ ଓ ଦ୍ୱିତୀୟଟି ସ୍ୱଭାବ। ବନାନର ସାନ ପାର୍ଥକ୍ୟ ଅନୁସାରେ ଠିକ୍ ଅର୍ଥ ବାଛିବାକୁ ହୁଏ।

ଉତ୍ତର

ଲକ୍ଷ — ଶହେ ହଜାର, ଲକ୍ଷ୍ୟ — ଉଦ୍ଦେଶ୍ୟ ବା ନିଶାଣ। କୁଳ — ବଂଶ, କୂଳ — ନଦୀ ଆଦିର ତୀର।

ଚରିତ — ଜୀବନ ବୃତ୍ତାନ୍ତ, ଚରିତ୍ର — ଆଚରଣ ବା ସ୍ୱଭାବ।

ପ୍ରବନ୍ଧଭିତ୍ତିକ ଟିପ୍ପଣୀ। ଗ୍ରୀସ ଓ ରୋମରେ ବୈଷୟିକ ଉନ୍ନତି ଇଚ୍ଛାକୃତ ଲକ୍ଷ୍ୟ ଥିଲା।

ମିଶରର ପ୍ରାଚୀନ ସଭ୍ୟତା ମଧ୍ୟ ସେହି ଆଦର୍ଶରେ ଅନୁପ୍ରାଣିତ। ଭାରତ ତ୍ୟାଗ ଓ ଆତ୍ମସଂଯମକୁ ପ୍ରାଧାନ୍ୟ ଦେଇ ମଧ୍ୟ ବୈଷୟିକ ନିଦର୍ଶନ ଛାଡ଼ିଛି।

ଏହି ତୁଳନାକୁ ଶିକ୍ଷକଙ୍କୁ ଦେଖାଇବି।

୩୦. ‘ସଭ୍ୟତା ଓ ବିଜ୍ଞାନ’ ତର୍କସଭା ପାଇଁ ଦୁଇ ପକ୍ଷର ବକ୍ତବ୍ୟ ଦିଅ।

ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ସପକ୍ଷ ଦଳକୁ ପ୍ରଶ୍ନ ଦିଅ—ଚିକିତ୍ସା ଓ ଯାତାୟାତର ଦୃଷ୍ଟାନ୍ତରୁ ମଣିଷର କେଉଁ ପ୍ରୟୋଜନ ପୂରଣ ହେଉଛି? ଅପରପକ୍ଷକୁ ପଚାର—ଯୁଦ୍ଧରେ ଅନିଷ୍ଟର କାରଣ ଜ୍ଞାନ ନା ତାହାର ବ୍ୟବହାର?
  2. ସଭାପତି ଦୁଇ ଦଳର ଦୃଷ୍ଟାନ୍ତକୁ ମେଳାଇ କହିପାରନ୍ତି ଯେ ବିଜ୍ଞାନ କାମ କରିବାର ଶକ୍ତି ଦିଏ, କାମର ଲକ୍ଷ୍ୟ ମଣିଷର ଆଦର୍ଶରୁ ଆସେ। ଏହି ନିଷ୍କର୍ଷକୁ ନେଇ ଶ୍ରେଣୀର ପ୍ରଶ୍ନ ନିଆଯାଇପାରେ।

ଉତ୍ତର

ସପକ୍ଷ — ରେଳ ଦୂରତା କମାଇଛି, ଚିକିତ୍ସା ରୋଗରୁ ମୁକ୍ତି ଦେଇଛି, ତେଣୁ ବିଜ୍ଞାନ ସଭ୍ୟତାକୁ ଆଗେଇ ନିଏ। ବିଚାରର ଅନ୍ୟ ପକ୍ଷ — ଯୁଦ୍ଧରେ ଜ୍ଞାନର ଅପପ୍ରୟୋଗ ହେଲେ ମଣିଷ କ୍ଷତିଗ୍ରସ୍ତ ହୁଏ, ତେଣୁ ଆବିଷ୍କାର ମାତ୍ରେ ମଙ୍ଗଳ ନିଶ୍ଚିତ ନୁହେଁ।

ସଭାପତିଙ୍କ ମତ — ଜ୍ଞାନ ସହ କର୍ତ୍ତବ୍ୟବୋଧ ଯୋଡ଼ିବା ଦରକାର। ପ୍ରତ୍ୟେକ ଦଳ ଗୋଟିଏ ପାଠଗତ ଉଦାହରଣ ଦେଇ ପରପକ୍ଷର ପ୍ରଶ୍ନର ଉତ୍ତର ଦେବ।
