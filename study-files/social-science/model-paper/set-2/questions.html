ପ୍ରତ୍ୟେକ ପ୍ରଶ୍ନର ଚାରୋଟି ବିକଳ୍ପରୁ ଗୋଟିଏ ଉତ୍ତର ବାଛ |

  1. ଗାନ୍ଧିଜୀଙ୍କ ପ୍ରାରମ୍ଭିକ କାର୍ଯ୍ୟ। “ଗାନ୍ଧିଜୀଙ୍କ ଜନ୍ମସ୍ଥାନ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍
    2. ପୋରବନ୍ଦର
    3. ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ
    4. ରାଜକୁମାର ଶୁକ୍ଳ

  2. କ୍ରମରେ ମେଳାଅ। (କ) ଦକ୍ଷିଣ ଆଫ୍ରିକାରେ ଭାରତୀୟଙ୍କ ପ୍ରତି ଅନ୍ୟାୟ ପ୍ରଚାର ପାଇଁ ପତ୍ରିକା। (ଖ) ଚମ୍ପାରନ୍‌ର ଚାଷୀଙ୍କ ପାଇଁ ଗାନ୍ଧିଜୀଙ୍କୁ ନିମନ୍ତ୍ରଣ କରିଥିବା ବ୍ୟକ୍ତି।

    1. ପୋରବନ୍ଦର / ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ
    2. ନାଟାଲ୍ ଭାରତୀୟ କଂଗ୍ରେସ / ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍
    3. ରାଜକୁମାର ଶୁକ୍ଳ / ପୋରବନ୍ଦର
    4. ଇଣ୍ଡିଆନ୍ ଓପିନିଅନ୍ / ରାଜକୁମାର ଶୁକ୍ଳ

  3. ଜାତୀୟ ଆନ୍ଦୋଳନର ଘଟଣାକ୍ରମ। “ସାବରମତୀ ଆଶ୍ରମରୁ ଦାଣ୍ଡି ଅଭିମୁଖେ ଯାତ୍ରାର ଆରମ୍ଭ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ୨୧ ଅକ୍ଟୋବର ୧୯୪୩
    2. ୧ ଅଗଷ୍ଟ ୧୯୨୦
    3. ୬ ଏପ୍ରିଲ ୧୯୩୦
    4. ୧୨ ମାର୍ଚ୍ଚ ୧୯୩୦

  4. “୨୧ ଅକ୍ଟୋବର ୧୯୪୩” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ସିଙ୍ଗାପୁରରେ ଆଜାଦ୍ ହିନ୍ଦ୍ ସରକାର ଗଠନ
    2. ସାବରମତୀ ଆଶ୍ରମରୁ ଦାଣ୍ଡି ଅଭିମୁଖେ ଯାତ୍ରାର ଆରମ୍ଭ
    3. ଅସହଯୋଗ ଆନ୍ଦୋଳନର ଆନୁଷ୍ଠାନିକ ଆରମ୍ଭ
    4. ଦାଣ୍ଡି ସମୁଦ୍ରକୂଳରେ ଲବଣ ଆଇନ ଭଙ୍ଗ

  5. ପ୍ରଥମ ଓ ଦ୍ୱିତୀୟ ପଞ୍ଚବାର୍ଷିକ ଯୋଜନାର ପ୍ରାଥମିକତାକୁ ଠିକ୍ କ୍ରମରେ ବାଛ।

    1. ଉଭୟରେ କେବଳ ପ୍ରତିରକ୍ଷା
    2. ଶିଳ୍ପ, ତା’ପରେ କୃଷି ଓ ଜଳସେଚନ
    3. ଉଭୟରେ କେବଳ ଶିଳ୍ପ
    4. କୃଷି ଓ ଜଳସେଚନ, ତା’ପରେ ଶିଳ୍ପ

  6. “ଚମ୍ପାରନ୍” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ଆଜାଦ୍ ହିନ୍ଦ୍ ସରକାର ପ୍ରତିଷ୍ଠାର ସ୍ଥାନ
    2. ୧୯୨୯ରେ ପୂର୍ଣ୍ଣ ସ୍ୱରାଜ ଲକ୍ଷ୍ୟ ନିର୍ଦ୍ଧାରଣ କରିଥିବା କଂଗ୍ରେସ ଅଧିବେଶନ
    3. ତିନିକାଠିଆ ବ୍ୟବସ୍ଥାର ପ୍ରତିବାଦ
    4. ବାଲେଶ୍ୱର ଜିଲ୍ଲାର ଲବଣ ସତ୍ୟାଗ୍ରହ କେନ୍ଦ୍ର

  7. ସ୍ୱାଧୀନତା ସଂଗ୍ରାମର ପରିଚୟ। “ନେତାଜୀ ନିକୋବରକୁ ଦେଇଥିବା ନାମ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ସ୍ୱରାଜ
    2. କର ବା ମର
    3. ଶହୀଦ
    4. ଝାନ୍‌ସୀ ରାଣୀ ବ୍ରିଗେଡ୍

  8. କ୍ରମରେ ମେଳାଅ। (କ) ଆଜାଦ୍ ହିନ୍ଦ୍ ଫୌଜର ମହିଳା ଶାଖା। (ଖ) ନେତାଜୀ ଆଣ୍ଡାମାନକୁ ଦେଇଥିବା ନାମ।

    1. କର ବା ମର / ଝାନ୍‌ସୀ ରାଣୀ ବ୍ରିଗେଡ୍
    2. ଝାନ୍‌ସୀ ରାଣୀ ବ୍ରିଗେଡ୍ / ଶହୀଦ
    3. ସ୍ୱରାଜ / କର ବା ମର
    4. ଶହୀଦ / ସ୍ୱରାଜ

  9. ଓଡ଼ିଶା ପ୍ରଦେଶ ଗଠନର ପଟଭୂମି। “ଓଡ଼ିଶାରେ ଇଂରେଜ ଶାସନ ପ୍ରତିଷ୍ଠା” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ୧୯୦୩
    2. ୧୮୦୩
    3. ୧୯୩୬
    4. ୧୮୬୬

  10. “୧୯୦୩” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ଉତ୍କଳ ସମ୍ମିଳନୀର ପ୍ରଥମ ଅଧିବେଶନ
    2. ଓଡ଼ିଶାରେ ଇଂରେଜ ଶାସନ ପ୍ରତିଷ୍ଠା
    3. ନଅଙ୍କ ଦୁର୍ଭିକ୍ଷ
    4. ସ୍ୱତନ୍ତ୍ର ଓଡ଼ିଶା ପ୍ରଦେଶ ଗଠନ

  11. ଜଣେ ଚାଷୀ ଚାଷ ଆରମ୍ଭର ଖର୍ଚ୍ଚ ଉଠାଇ ପାରୁନଥିଲେ। ପାଠରେ ବର୍ଣ୍ଣିତ କେଉଁ ସହାୟତା ତାଙ୍କ ପାଇଁ ସିଧାସଳଖ ପ୍ରଯୁଜ୍ୟ?

    1. ଗ୍ରାମଜ୍ୟୋତି ଯୋଜନା
    2. ଶିଳ୍ପ ତାଲିମ
    3. ତକାଭି ଋଣ
    4. ଗଡ଼ଜାତ ମିଶ୍ରଣ

  12. “ହରେକୃଷ୍ଣ ମହତାବ” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ନିଜ ପ୍ରଧାନମନ୍ତ୍ରୀ ପଦର ଦରମା ଉତ୍କଳ ବିଶ୍ୱବିଦ୍ୟାଳୟକୁ ଦାନ
    2. ଓଡ଼ିଶା ସହ ଗଡ଼ଜାତ ମିଶ୍ରଣ ସମୟରେ ସରକାରର ନେତୃତ୍ୱ
    3. ଉତ୍କଳ ସମ୍ମିଳନୀ ଗଠନ ଉଦ୍ୟମରେ ଉତ୍କଳ ଗୌରବ
    4. ଉତ୍କଳ ସମ୍ମିଳନୀର ପ୍ରଥମ ଅଧିବେଶନର ସଭାପତି

  13. ସ୍ୱାଧୀନତା ଓ ଶାସନ। “ପାକିସ୍ତାନର ପ୍ରଥମ ପ୍ରଧାନମନ୍ତ୍ରୀ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ମହମ୍ମଦ ଅଲ୍ଲୀ ଜିନ୍ନା
    2. ଲିଆକତ୍ ଅଲ୍ଲୀ ଖାଁ
    3. ଲର୍ଡ ମାଉଣ୍ଟବ୍ୟାଟେନ
    4. ଜବାହରଲାଲ ନେହେରୁ

  14. ମିଳନ ପତ୍ରରେ ଦେଶୀୟ ରାଜ୍ୟରୁ ଭାରତକୁ ଆସିଥିବା ତିନି ଦାୟିତ୍ୱ ମଧ୍ୟରେ କେଉଁଟି ପଡ଼େ?

    1. କୃଷି ଋଣ ବଣ୍ଟନ
    2. ପ୍ରାଥମିକ ଶିକ୍ଷା
    3. ସ୍ଥାନୀୟ ହାଟ ପରିଚାଳନା
    4. ପ୍ରତିରକ୍ଷା

  15. ବିକାଶ ଓ ରାଷ୍ଟ୍ରଗଠନ। “ଶହେରୁ କମ୍ ଲୋକ ଥିବା ଗାଁର ବିଦ୍ୟୁତୀକରଣ ପାଇଁ ରାଜ୍ୟ ଯୋଜନା” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    1. ବିଜୁ ଗ୍ରାମଜ୍ୟୋତି
    2. APPLE
    3. ମିଳନ ପତ୍ର
    4. ତକାଭି ଋଣ

  16. “APPLE” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    1. ୧୯୮୧ ଜୁନ୍‌ରେ ଉତ୍‌କ୍ଷେପିତ ଭାରତୀୟ ଯୋଗାଯୋଗ ଉପଗ୍ରହ
    2. ଚାଷ ଆରମ୍ଭ କରିବାକୁ କୃଷକଙ୍କୁ ଦିଆଯାଉଥିବା ଋଣ
    3. ଶହେରୁ କମ୍ ଲୋକ ଥିବା ଗାଁର ବିଦ୍ୟୁତୀକରଣ ପାଇଁ ରାଜ୍ୟ ଯୋଜନା
    4. ପଟେଲ ଓ ମେନନଙ୍କ ଦ୍ୱାରା ଦେଶୀୟ ରାଜ୍ୟର ମିଶ୍ରଣ ପାଇଁ ପ୍ରସ୍ତୁତ ଦଲିଲ

  17. ରାଜ୍ୟ ପୁନଃଗଠନ। “୧୯୬୧ରେ ଭାରତରେ ମିଶି ୧୯୮୭ରେ ରାଜ୍ୟ ହୋଇଥିବା ଅଞ୍ଚଳ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    4. କର୍ଣ୍ଣାଟକ

  18. “ତାମିଲନାଡୁ” ପାଇଁ ପାଠର ଠିକ୍ ପରିଚୟ ବାଛ।

    3. ୧୯୬୧ରେ ଭାରତରେ ମିଶି ୧୯୮୭ରେ ରାଜ୍ୟ ହୋଇଥିବା ଅଞ୍ଚଳ
    4. ମହୀଶୂର ରାଜ୍ୟର ପରିବର୍ତ୍ତିତ ନାମ

  19. ନିର୍ବାଚନର ପରିସ୍ଥିତି। “ନିର୍ଦ୍ଧାରିତ ସମୟ ପୂର୍ବରୁ ସଭା ଭଙ୍ଗ ହେତୁ ନୂଆ ସଭା ଚୟନ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?

    2. ମଧ୍ୟବର୍ତ୍ତୀକାଳୀନ ନିର୍ବାଚନ
    3. ପ୍ରତ୍ୟକ୍ଷ ନିର୍ବାଚନ
    4. ପରୋକ୍ଷ ନିର୍ବାଚନ

  20. କ୍ରମରେ ମେଳାଅ। (କ) ନିର୍ବାଚକ ମଣ୍ଡଳୀ ମାଧ୍ୟମରେ ରାଷ୍ଟ୍ରପତି ବାଛିବାର ପଦ୍ଧତି। (ଖ) ସଭା ଭଙ୍ଗ ନ ହୋଇ ଗୋଟିଏ ଆସନର ଅବଶିଷ୍ଟ କାଳ ପାଇଁ ଚୟନ।

    1. ମଧ୍ୟବର୍ତ୍ତୀକାଳୀନ ନିର୍ବାଚନ / ପ୍ରତ୍ୟକ୍ଷ ନିର୍ବାଚନ
    2. ପରୋକ୍ଷ ନିର୍ବାଚନ / ଉପ-ନିର୍ବାଚନ

  21. ରାସ୍ତାରେ ନିଷ୍ପତ୍ତି। “ଏକ ଯାନରେ ଅନେକ ଯାତ୍ରୀ ଯାଇ ଇନ୍ଧନ ସଞ୍ଚୟ” ସହ କେଉଁ ଉତ୍ତର ମେଳ ଖାଏ?
