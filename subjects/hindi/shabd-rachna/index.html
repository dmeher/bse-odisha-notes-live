दीर्घ ସ୍ୱରରେ सन्धि ଓ सन्धि-विच्छेद

ଦୁଇ ଶବ୍ଦ ମିଶିବାବେଳେ ପ୍ରଥମର ଶେଷ ଧ୍ୱନି ଓ ଦ୍ୱିତୀୟର ପ୍ରଥମ ଧ୍ୱନିରେ ପରିବର୍ତ୍ତନ ହେଲେ ସନ୍ଧି ହୁଏ। ମିଳିଥିବା ଶବ୍ଦକୁ ମୂଳ ଶବ୍ଦରେ ଫେରାଇବା ହେଉଛି विच्छेद। ସମାନ ଶ୍ରେଣୀର ଦୁଇ ସ୍ୱରରୁ ଦୀର୍ଘ ସ୍ୱର ହେବାର ଉଦାହରଣ ‘विद्या + आलय → विद्यालय’ ଓ ‘रवि + इन्द्र → रवीन्द्र’। ବିଚ୍ଛେଦ କଲାବେଳେ ମୂଳ ଶବ୍ଦର ନିଜ ବନାନ ଫେରାଇ ଲେଖ।

  1. ‘विद्यालय’ର ଅର୍ଥରେ ବିଦ୍ୟା ଓ ଆଳୟ ଚିହ୍ନ। ବିଚ୍ଛେଦରେ ସେମାନଙ୍କ ନିଜ ହିନ୍ଦୀ ବନାନ विद्या ଓ आलय ଲେଖ।
  2. ମଝିର ମିଳନରେ आ + आ → आ। ମିଶିଥିବା ଶବ୍ଦରେ ଗୋଟିଏ ଦୀର୍ଘ ସ୍ୱର ଶୁଣାଯାଏ।
  3. ‘रवीन्द्र’ରେ ଏଥର इ + इ → ई। ବିଚ୍ଛେଦ କଲେ रवि ଓ इन्द्र ରୂପ ଫେରେ।

गुण ଓ वृद्धि ସ୍ୱରସନ୍ଧି

अ ବା आ ପରେ इ/ई ଆସିଲେ ए ଏବଂ उ/ऊ ଆସିଲେ ओ ମିଳିବା ଗୁଣସନ୍ଧିର ଉଦାହରଣ। ‘सूर्य + उदय → सूर्योदय’ରେ ପ୍ରଥମ ଶବ୍ଦର ଶେଷ ସ୍ୱର ଓ ‘उदय’ର उ ମିଶିଛି।

यण ଓ अयादि ସନ୍ଧି

इ ବା ई ପରେ ଭିନ୍ନ ସ୍ୱର ଥିଲେ य्, उ ବା ऊ ପରେ ଭିନ୍ନ ସ୍ୱର ଥିଲେ व् ଏବଂ ऋ ପରେ ଭିନ୍ନ ସ୍ୱର ଥିଲେ र् ହେବା ଯଣ୍ ସନ୍ଧି। ‘यदि + अपि → यद्यपि’, ‘अनु + एषण → अन्वेषण’ ଉଦାହରଣ।

ଅୟାଦିରେ ए, ऐ, ओ, औ ପରେ ଭିନ୍ନ ସ୍ୱର ଆସିଲେ ଯଥାକ୍ରମେ अय्, आय्, अव्, आव् ହୁଏ। ‘ने + अन → नयन’ରେ ଏହି ପରିବର୍ତ୍ତନ ପଢ଼ିହୁଏ।

व्यंजन सन्धिରେ ପଡ଼ୋଶୀ ଧ୍ୱନିର ପ୍ରଭାବ

ବ୍ୟଞ୍ଜନ ପରେ କେଉଁ ଧ୍ୱନି ଆସିଛି ତାହା ଅନୁସାରେ ପ୍ରଥମ ଧ୍ୱନି ବଦଳିପାରେ। ‘दिक् + अम्बर → दिगम्बर’ରେ क् ଠାରୁ ग् ହେଉଛି।

‘सम् + कल्प → संकल्प’ ଓ ‘सम् + तोष → संतोष’ରେ ନାସିକ୍ୟ ଧ୍ୱନିର ଲେଖା ବଦଳିଛି। ତାଲିକାର त्/द् ସହ ଅନ୍ୟ ଧ୍ୱନି ଯୋଗର ଉଦାହରଣଗୁଡ଼ିକୁ ପଢ଼ିବାବେଳେ ପ୍ରଥମେ ବିଚ୍ଛେଦ କରି ଧ୍ୱନିର ରୂପାନ୍ତର ଚିହ୍ନଟ କର।

विसर्ग सन्धि

ବିସର୍ଗ ପରବର୍ତ୍ତୀ ଧ୍ୱନି ଅନୁସାରେ ସ୍ଥାନ ବଦଳାଏ, ଅନ୍ୟ ଧ୍ୱନିରେ ପରିଣତ ହୁଏ ବା ଲୋପ ପାଏ। ‘निः + चल → निश्चल’ରେ श्, ‘मनः + ताप → मनस्ताप’ରେ स् ଏବଂ ‘निः + उपाय → निरुपाय’ରେ र् ମିଳେ।

‘अतः + एव → अतएव’ରେ ବିସର୍ଗ ଲୋପ ହୋଇଛି। ମୂଳରେ ବିସର୍ଗ ଥିବା ବିଚ୍ଛେଦ ମନେ ରଖିଲେ ଏହାକୁ ସାଧାରଣ ବ୍ୟଞ୍ଜନ ସନ୍ଧି ସହ ମିଶାଇବାର ଭୁଲ କମେ।

समास-विग्रह ଓ अव्ययीभाव

ସମାସରେ ଦୁଇ ବା ଅଧିକ ସାର୍ଥକ ପଦ ମିଶି ସଂକ୍ଷିପ୍ତ ସମସ୍ତପଦ ହୁଏ। ପଦଗୁଡ଼ିକ ମଧ୍ୟରେ ଥିବା ସମ୍ପର୍କକୁ ଖୋଲି କହିଲେ विग्रह।

तत्पुरुषର ଛଅ କାରକ ସମ୍ପର୍କ
