ଉତ୍ତର ଦେଖନ୍ତୁ

ବ୍ୟାଖ୍ୟା

  1. ପ୍ରଥମ ଶୀର୍ଷକୁ ଆଧାର କଲେ ଅନ୍ୟ ଦୁଇ ଶୀର୍ଷର ସ୍ଥାନାଙ୍କ ଅନ୍ତର (−2, −3) ଓ (2, 1)। ଦୁଇଗୁଣ କ୍ଷେତ୍ରଫଳ = |(−2)(1) − (−3)(2)| = 4।
  2. B = 2D − A = (−2 − 1, −4 − 1) = (−3, −5)।
  3. C = 2E − A = (6 − 1, 4 − 1) = (5, 3)।
  4. 2 × କ୍ଷେତ୍ରଫଳ = |(1)(−8) + (−3)(2) + (5)(6)| = |16|।
  5. 16/2 = 8 ବର୍ଗ ଏକକ।

ଉତ୍ତର

B(−3, −5), C(5, 3)। କ୍ଷେତ୍ରଫଳ 8 ବର୍ଗ ଏକକ।
