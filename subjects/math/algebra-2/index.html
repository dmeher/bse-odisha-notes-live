ଆଦର୍ଶ ପ୍ରଶ୍ନପତ୍ର · ସେଟ୍ ୧, ଭାଗ ୨, ପ୍ରଶ୍ନ ୧a · ବିକଳ୍ପ ୧ (୫ ନମ୍ବର)

ଉତ୍ତର ଦେଖନ୍ତୁ
  1. a = 1, b = −5, c = 6। ପ୍ରଭେଦକ D = 25 − 24 = 1 > 0।
  2. x = (−b ± √D)/(2a) = (5 ± 1)/2।

  4. ସମଷ୍ଟି 2 + 3 = 5 = −b/a। ଗୁଣଫଳ 2 × 3 = 6 = c/a।
